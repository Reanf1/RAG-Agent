# Bad Case分析与优化报告

## 1 分类、根因与代表案例

按检索失败、生成幻觉、引用错误、Agent错误四类记录，可一题多类。先核对问题条件、原文与完整轨迹，再定位缺失证据、模型解释、来源映射或工具规划；不能只看“调用成功”。原始[案例清单](5_5_3%20Bad%20Case%E5%88%86%E6%9E%90%E4%B8%8E%E4%BC%98%E5%8C%96/Bad_Case%E6%B8%85%E5%8D%95.json)、[全题风险索引](5_5_3%20Bad%20Case%E5%88%86%E6%9E%90%E4%B8%8E%E4%BC%98%E5%8C%96/%E5%85%A8%E9%A2%98%E9%A3%8E%E9%99%A9%E7%B4%A2%E5%BC%95.json)。

| 题号 | 类型 | 现象与根因/处理 |
| --- | --- | --- |
| F005 | 检索/生成 | 通用概念或T2T问题没有取得对应证据；路径和答案分别判定 |
| F002 | 检索/生成 | ImageNet限定遗漏或单段证据不足后误拒答；新轮仍需核对训练条件 |
| R001 | 生成 | ViT/CNN比较把观察解释成无依据因果；需要论文条件与推断标注 |
| F001 | 引用 | RAG完整回答经Agent改写丢来源；简单报告直接保留，不能据此保证引用语义 |
| R015 | 生成/引用 | 混淆ImageNet-only与JFT训练；应核对数据规模、骨干和指标 |
| C006 | Agent | 错误论文ID导致工具失败；映射真实列表ID后减少无效调用 |
| S009 | Agent/完整性 | 三篇任务只比较两篇；参数合法不代表任务覆盖完整 |
| S013 | Agent | 同名工具不同参数曾被过度拒绝；区分独立任务，仍有生成边界 |
| S014 | Agent | 群组意图误选文件或漏任务；覆盖目标与正文证据逐项核对 |
| C013 | Agent/生成 | DeiT/CaiT机制任务错用论文ID或误称缺文档；补丁后仍有失败 |

## 2 已完成的一轮前后对照（2026-10-03）

同60题、冻结索引/seed，改动集中于真实ID映射和单一RAG完整答案保留；失败仍在分母。单次前后运行不是严格因果实验。见[对照数据](5_5_3%20Bad%20Case%E5%88%86%E6%9E%90%E4%B8%8E%E4%BC%98%E5%8C%96/%E4%BC%98%E5%8C%96%E5%89%8D%E5%90%8E%E5%AF%B9%E6%AF%94%E6%95%B0%E6%8D%AE.json)、[后测原答](5_5_3%20Bad%20Case%E5%88%86%E6%9E%90%E4%B8%8E%E4%BC%98%E5%8C%96/Agent%E4%BC%98%E5%8C%96%E5%90%8E60%E9%A2%98_20261003.json)、[数值复核](5_5_3%20Bad%20Case%E5%88%86%E6%9E%90%E4%B8%8E%E4%BC%98%E5%8C%96/%E8%BF%AD%E4%BB%A3%E6%95%B0%E5%80%BC%E5%A4%8D%E6%A0%B8.json)。

## 3 最新补丁与定向验证（2026-10-09）

完整120条rag-v20结果冻结于补丁前，质量见[系统评测报告](%E7%B3%BB%E7%BB%9F%E8%AF%84%E6%B5%8B%E6%8A%A5%E5%91%8A.md)。后续业务补丁2c0353c集中修正两项可复现缺陷：正文任务不足不能被关键词/列表或其他论文成功误清除；共享BGE分词、分窗和预测一起互斥，避免并发Already borrowed错误。

验证层次分别记录：两端各853项回归通过；7条原失败轨迹回放阻止误完成；56次真实并发为32读库、8Embedding、8重排、8混合查询，修复前53成功/3异常，修复后56成功/0异常。探针不是多用户吞吐量或模型答案实验。

再对F010/F012/C013/S005两组共8条真正重新生成，28次模型HTTP无执行异常：

| 题号 | default | no_rules | 当前结论 |
| --- | --- | --- | --- |
| F010 | 事实正确但缺正文引用 | 事实与来源通过 | 1通过、1缺引用 |
| F012 | 三项改进与来源通过 | 三项改进与来源通过 | 2通过 |
| C013 | 文献存在却因证据不足误称不存在 | 错用Conditional DETR作为DeiT | 两组失败 |
| S005 | 仅抽取问题关键词，未回答演进 | 同类失败 | 两组失败 |

合计3通过、1缺引用、4失败。拦截误完成保留诚实状态，但并未自动生成正确正文；不能改写补丁前120条分数或宣称全量质量改善。见[定向原答](5_5_3%20Bad%20Case%E5%88%86%E6%9E%90%E4%B8%8E%E4%BC%98%E5%8C%96/%E6%9C%80%E7%BB%88%E8%B4%A8%E9%87%8F%E6%94%B6%E5%B0%BE_20261009/Windows%E8%A1%A5%E4%B8%81%E5%A4%8D%E6%B5%8B/targeted-agent.json)、[调用日志](5_5_3%20Bad%20Case%E5%88%86%E6%9E%90%E4%B8%8E%E4%BC%98%E5%8C%96/%E6%9C%80%E7%BB%88%E8%B4%A8%E9%87%8F%E6%94%B6%E5%B0%BE_20261009/Windows%E8%A1%A5%E4%B8%81%E5%A4%8D%E6%B5%8B/targeted-agent.calls.jsonl)、[定向核验](5_5_3%20Bad%20Case%E5%88%86%E6%9E%90%E4%B8%8E%E4%BC%98%E5%8C%96/%E6%9C%80%E7%BB%88%E8%B4%A8%E9%87%8F%E6%94%B6%E5%B0%BE_20261009/Windows%E8%A1%A5%E4%B8%81%E5%A4%8D%E6%B5%8B/targeted-verification.json)、[并发数据](5_5_3%20Bad%20Case%E5%88%86%E6%9E%90%E4%B8%8E%E4%BC%98%E5%8C%96/%E6%9C%80%E7%BB%88%E8%B4%A8%E9%87%8F%E6%94%B6%E5%B0%BE_20261009/Windows%E8%A1%A5%E4%B8%81%E5%A4%8D%E6%B5%8B/parallel-after.json)、[原轨迹回放脚本](5_5_3%20Bad%20Case%E5%88%86%E6%9E%90%E4%B8%8E%E4%BC%98%E5%8C%96/%E6%9C%80%E7%BB%88%E8%B4%A8%E9%87%8F%E6%94%B6%E5%B0%BE_20261009/replay_incomplete_observation.py)。
