# Bad Case 分析报告

当前尚未运行系统评测，没有已确认的失败案例。

## 1 分类

| 类型 | 判定依据 |
| --- | --- |
| 检索失败 | 标注的相关来源未召回 |
| 生成错误 | 答案错误或遗漏关键事实 |
| 引用错误 | 来源错误、位置错误或来源不支持答案 |
| Agent 决策错误 | 选错工具、无效调用或循环无法完成 |

## 2 逐例记录

每例记录问题标识、预期、实际结果、相关原文、检索/工具记录、根因、改动和复测结果。涉及多个问题时可记录多个分类。

## 3 优化验证

至少开展一轮迭代，使用相同评测集和评分方法记录前后结果；说明改善、退化及尚未解决的失败。
