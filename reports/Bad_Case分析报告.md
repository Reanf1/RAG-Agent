# Bad Case 分析报告

本报告保留2026-09-30模块一、二的历史失败记录（第1～3节），第4节起新增2026-10-03的60题系统评测Bad Case与迭代。原始数据保持不变；独立人工质量评分仍待评阅人填写。自动化通过不能排除模型质量问题。

## 1 分类

| 类型 | 判定依据 |
| --- | --- |
| 检索失败 | 标注的相关来源未召回 |
| 生成错误 | 答案错误或遗漏关键事实 |
| 引用错误 | 缺正文标记/来源字段，来源错误、位置错误或内容不支持答案 |
| Agent 决策错误 | 选错工具、无效调用或循环无法完成 |

## 2 逐例记录

### BC-01：Transformer问题混用BERT参数

- 问题：原始Transformer用了多少注意力头，每头键/值维度是多少？预期8头、键/值各64维，依据Attention第5物理页的`h = 8`与`d_k = d_v = d_model/h = 64`。
- 实际：两篇完整论文入库248块；Top-1为BERT第3物理页（0.582784），Top-2是Attention第5页的3.2.3段落（0.460953），Top-5缺目标事实块。模型用BERT的12/16头代答，并把每头维度错误推断为隐藏维度H。
- 分类/根因：检索失败、生成错误、引用不支持目标陈述。跨语言候选/排序不充分，模型没有区分原始Transformer与BERT，且没有在依据不足时正确限制推断；页码映射正确不能解决此问题。
- 证据：[连接JSON](模块完整性验证/模块一二连接验证结果_20260930.json)的`heads`请求，包含全部Top-5、原文、答案、引用与Token。
- 后续方向：检查目标块是否进入RRF Top-20，再区分候选召回与重排损失；研究论文范围限定，并加强缺依据/模型实体区分。未实施优化，没有改善数据。

### BC-02：英文事实数字正确但正文无引用

- 问题：列出BERT-base与BERT-large的层数、隐藏维度、注意力头数。
- 实际：模型回答12/768/12和24/1024/16，但未在正文给出`[参考文档N]`。另一次固定上下文流式回答只在末尾来源区写编号。
- 分类/根因：引用错误。模型未遵循正文引用格式；解析器正确拒绝把末尾编号当作正文溯源，页面警告且缓存不写入。
- 证据：[连接JSON](模块完整性验证/模块一二连接验证结果_20260930.json)的`bert-sizes`、[流式JSON](5_2_2%20流式输出与引用/流式引用复测结果_20260930.json)前两题和[日志JSON](5_2_4%20日志与可观测性/RAG日志复测结果_20260930.json)。日志中的相同问题重新生成而没有假称缓存加速。
- 后续方向：比较明确的逐事实引用要求、验证模型遵循率；不能自动添加未经模型陈述对应的来源冒充修复。明确要求正文引用的流式变体本轮成功，但不是相同输入优化前后实验。

### BC-03：有依据却拒答，合法引用仍被缓存

- 问题：原始Transformer用了多少个注意力头？
- 实际：两个标注片段的中文缓存探测中，原文明确有`h = 8`，模型却答“头数量未在提供的文档中明确提及”，并给出合法正文引用。精确与近似问题原样复用该错答，均跳过检索/生成。
- 分类/根因：生成错误。缓存当前只验证正常结束、有效编号/来源和无警告，不能判断语义正确性。缓存机制正常工作不等于答案准确。
- 证据：[缓存JSON](5_2_3%20缓存与降级策略/语义缓存复测结果_20260930.json)第0～2请求，保留原文与完整回答；第3请求因英文缺正文引用而失败，`validation_complete=false`。
- 后续方向：优先修复生成对明确证据的利用，评估事实与引用语义校验成本；不要只调整相似度阈值。尚未实施改动。

### BC-04：低相关候选存在，但模型说未找到文档

- 实际：票价问题检索出两个低相关论文块，用户确认后生成；系统明确标记low模式、显示候选，模型仍写“当前知识库中未找到相关文档”。
- 分类/根因：生成措辞错误。模型混淆“有候选但不能回答”与“空知识库”；系统行为及真实检索记录保留正确状态。
- 证据：[降级JSON](5_2_3%20缓存与降级策略/降级策略复测结果_20260930.json)的低相关确认请求。后续应在相同输入上验证这两类措辞，未声称本轮已修复。

## 4 本轮范围与判定口径

基线采用5.5.2已冻结的12篇视觉Transformer论文、60题（四类各15题，中英文各30题），对照默认候选20、最终Top-5的混合检索+BGE重排和默认Agent。五组检索300条、两组Agent120条原始记录不覆盖；本轮Agent比较仅使用其中默认60题。

类别允许重叠。页级检索风险按“论文SHA+物理页”的金标准识别：20/60题没有任何标注页命中，37/60题未覆盖全部目标论文。F005第5页、F010的其他论文也含等价事实，是固定标注页不完整的具体例子；不回改金标准以抬高成绩。37题自动风险不等于37个语义错答；不把缺标注页命中直接判为最终答案错误。全部题目见[风险索引](5_5_3%20Bad%20Case分析与优化/全题风险索引.json)，10个代表例的原始答案、调用、排名、金标准及原文片段见[Bad Case清单](5_5_3%20Bad%20Case分析与优化/Bad_Case清单.json)。

独立检索使用固定原问题；Agent可能改写问题或限定doc_id，语义案例以实际工具片段再次核对，不能直接用独立排名推断全部Agent检索。

生成与引用语义案例依据原文逐例开发复核；未将参考答案关键词匹配当成人工分数。人工表仍保持待填。工具路径准确率沿用锁定规则，不等于参数正确率或任务成功率；模型自报完成也不等于答案正确。

## 5 四类案例、根因及改进

### BC55-01 / F005：生成错误、Agent决策错误

- 问题：T2T-ViT的两个主要架构组成是什么？
- 现象：金标准只列t2t_vit物理第2页；默认Top-1的第5页已明确T2T模块与T2T-ViT骨干，是标注页漏命中但语义有证据的例子。实际Agent把论文问题当一般概念直接回答，漏掉T2T模块与深窄骨干。
- 根因分析：规则路由的一般概念匹配优先于论文意图，绕过实际原文。固定证据页不是等价事实的穷尽标注，页级指标产生假阴性；不能把未命中标注页直接当语义检索失败。
- 改进：先确认论文意图再允许一般概念直答；后续由独立评阅人补充等价证据位置。本轮不修改冻结金标准、不改变检索与通用路由。
- 原文位置：t2t_vit 第2物理页；t2t_vit 第2物理页；原文文件位于[论文清单](5_5_1%20评测集构建/论文清单.json)的local_path，实际检索/工具引用片段保存在本轮清单中。

### BC55-02 / F002：生成错误

- 问题：Which dataset does DeiT use for training without external data?
- 现象：DeiT摘要明确说明仅用ImageNet、无外部数据；默认Top-5第3项为第1页图注，第4项为第2页贡献段，均明确no external data，工具仍声称没有相关文档并否定该训练设定。
- 根因分析：检索已提供明确限定条件，生成没有正确利用证据，并把有文档误说成空知识库；合法编号校验不能发现语义误拒答。
- 改进：区分空库/证据不足状态，针对问题限定条件核对证据；用原文相同输入验证生成，不靠降低相似阈值或人工改分。此轮保留为未解决项。
- 原文位置：deit 第1物理页；原文文件位于[论文清单](5_5_1%20评测集构建/论文清单.json)的local_path，实际检索/工具引用片段保存在本轮清单中。

### BC55-03 / R001：生成错误、引用错误

- 问题：Why can large-scale pretraining compensate for ViT’s weaker convolutional inductive biases?
- 现象：答案把缺少CNN归纳偏置时ViT在小数据上不易泛化，改成这些偏置使CNN表现不佳；引用编号来自ViT第2页，内容因果与主体错位。
- 根因分析：第2页开头是跨页续句，所引片段缺少上一页主体，可能促成主语误解；实际答案已发生主语与因果错位，记录不足以单独证明唯一成因。引用文件/页码存在不证明陈述受支持。
- 改进：保留句子前文或相邻块、检查主语/比较对象；引用语义仍需人工核验。此轮引用直通只避免二次丢失，不能校正RAG内部错误。
- 原文位置：vit 第2物理页；vit 第4物理页；原文文件位于[论文清单](5_5_1%20评测集构建/论文清单.json)的local_path，实际检索/工具引用片段保存在本轮清单中。

### BC55-04 / F001：引用错误

- 问题：ViT论文在模型规模实验中使用了哪三个训练数据集？
- 现象：RAG给出vit.pdf物理第4与第6页的完整引用，Observation最终只保留页数，丢失文件名与正文标记。
- 根因分析：Agent重复生成最终答案，未强制保留RAG已格式化的来源。
- 改进：本轮实施：单次工具完整回答原问题且grounded、answered、有有效引用、Observation确认完成时，直接保留该RAG答案；多步骤/资料不足不适用。
- 原文位置：vit 第4物理页；原文文件位于[论文清单](5_5_1%20评测集构建/论文清单.json)的local_path，实际检索/工具引用片段保存在本轮清单中。

### BC55-05 / R015：检索失败、生成错误、引用错误

- 问题：With only ImageNet available, which collected approaches offer better-supported starting points than requiring JFT pretraining, and why?
- 现象：问题限定只有ImageNet，应比较DeiT/T2T等起点；默认结果覆盖ViT但漏掉其他标注论文。模型将大规模预训练最佳结果解释为ImageNet-only，并把第6页不同模型规模表现相似说成ImageNet-21k与JFT预训练相似。
- 根因分析：跨论文覆盖不足；生成没有核对训练数据条件，将跨块指代their performances错误解释为数据集比较。来源编号合法，语义限定不支持该陈述。
- 改进：多论文问题按目标文献分别检索并汇总；保留性能表的训练条件、比较对象；逐条核对数字与限定条件。此轮不宣称语义引用已修复。
- 原文位置：vit 第4物理页；deit 第1物理页；t2t_vit 第1物理页；t2t_vit 第2物理页；原文文件位于[论文清单](5_5_1%20评测集构建/论文清单.json)的local_path，实际检索/工具引用片段保存在本轮清单中。

### BC55-06 / C006：Agent决策错误

- 问题：DETR和Deformable DETR的交叉注意力读取图像特征的方式有何不同？
- 现象：paper_compare接收DETR、Deformable DETR名称而非SHA-256，两次输入失败后第三轮重复签名终止。

- 改进：本轮实施：必填论文ID工具缺少足够已知ID时先paper_list；仅从成功列表将唯一文件名或干名转为真实SHA；歧义/未知名称仍拒绝猜测。

### BC55-07 / S009：Agent决策错误

### BC55-08 / S013：Agent决策错误

- 问题：综合DAB-DETR、DN-DETR和DINO，归纳DINO沿用的基础设计及三个新增方向。

### BC55-09 / S014：生成错误、Agent决策错误

### BC55-10 / C013：检索失败、生成错误

- 现象：DeiT与CaiT图像级预测机制对比应包含蒸馏token和class-attention；Top-5三块来自PVT，DeiT块谈性能，CaiT块谈LayerScale与结论，没有目标机制。最终答案遗漏关键机制，还加入无关PVT。

## 6 本轮实施与回归验证

业务只修改`src/agent/react_loop.py`两个交接点，39行补充：

1. 选择必填论文ID主工具时，若当前问题/Context缺少所需ID，先调用真实`paper_list`。后续Action仅将成功列表中唯一、大小写不敏感的文件名/干名转为实际SHA-256；未知名称、歧义、失败列表不猜测，不使用基准集专用别名。真实工具仍检查上传文件指纹。

## 8 改善、退化与残留问题

- **F001引用丢失已修复**：最终答案原样保留`vit.pdf`第4/6物理页及正文标记；没有猜测或补造来源。

- **C015参数修复后仍答非所问**：真实列表与真实ID论文对比成功，耗时35.49→144.83秒，模型自报完成；但回答方法、COCO和AP/PQ而不是500/50训练轮数。工具接口只输出方法/数据集/结果，规划需检查问题目标，必要时走针对训练设置的RAG。该例说明路径准确率不能当作任务正确率，也解释部分时延增加。
- **S009循环解除、错误论文范围仍在**：152.70→88.78秒、7→3轮，最终未完成并请求确认；实际KB过滤到DETR指纹，而原题是ViT/DINO/Conditional DETR。需在格式校验之外验证论文实体范围。

- **生成与语义引用仍待改进**：F002有no external data原文仍误拒答；F005仍绕过知识库；R001的主语/因果错误和R015训练数据限定错误被原样保留。完整来源文本让错误可核对，但不能自动校正错误。

后续优先顺序：先验证问题实体与工具任务范围、修正无参数列表调用；再对生成的训练条件/主语/数字做证据核对，按目标论文分别检索；最后在独立评阅后补充等价证据标注并重复质量评测。本轮已经完成至少一次真实迭代及对照，未宣称全部Bad Case解决。

## 9 结论边界与复现

这是一轮在发现问题的同一开发集上的迭代，不是独立测试集的泛化成绩。所有论文英文，查询中英文；页级标注不穷尽等价事实，参考答案还未独立人工复核。前测两种Agent交替运行、后测仅默认Agent顺序运行，缓存热态、负载、随机调用ID及模型采样可能影响结果；单遍时延不能证明纯粹代码因果，也没有方差/置信区间。

本轮未重跑五组独立检索，旧Hit@5/MRR/Recall仍作为基线风险依据，不能把它们标为优化后实测指标。原[120条人工评分表](5_5_2%20系统性能评估/答案质量人工评分表.xlsx)仍是旧两组答案，未混入新答案或伪造评分；本轮新60题及对照完整保存在JSON中，质量改善待评阅。
