# 分块策略对比实验报告

2026 年 9 月 29 日完成三种分块实现及基础统计。当前尚无检索召回数据，不据此宣布最优策略。

## 1 实验设计

按用户明确的范围，只对固定切分比较 `chunk_size=256/512/1024`；递归字符和句段切分各使用 `config.yaml` 的默认参数，目前为 512 字符大小、64 字符目标重叠，共五组设置。本次输入为同一 PDF 加载结果；固定切分的目标重叠也沿用默认 64 字符。实际重叠由策略规则决定，不是 Token 数。

后续检索实验保持这五组设置，使用同一文献集合、问题集合、Embedding 与检索配置，不对递归和句段策略另外开展大小参数对比。

样本复用学术 PDF 优化阶段的 [Attention Is All You Need](https://arxiv.org/pdf/1706.03762)，15 页，文件 SHA-256 为 `bdfaa68d8984f0dc02beaca527b76f207d99b666d31d1da728ee0728182df697`。实际 `load_pdf()` 返回 18 个内容单元：15 个正文页、3 个独立表格。独立表格三种策略均整块保留，因此正文统计与表格分列，不让表格保护例外混淆限长结果。原文与解析边界见 [学术 PDF 解析记录](../docs/QA/5.1.2%20学术论文PDF解析优化.md)。

## 2 记录项目

本次实际记录块数、最短/最长/平均字符长度和表格数量，并验证正文限长和字符区间。构建时间、检索召回与 Hit@5/MRR、完整质量实验待检索层接入后记录。来源保留、跨页表格保护和公式原位置继承通过对应功能测试，不等于学术语义完整性的人评。

环境：项目 `.venv` 的 Python 3.10.10、PyMuPDF 1.28.2、langchain-core 0.3.29、langchain-text-splitters 0.3.5。已按上述五组设置重新统计，递归和句段调用仅指定策略名，由入口读取默认大小/重叠；普通正文均不超过大小上限。

| 策略 | 字符大小 | 正文块数 | 正文最短 | 正文最长 | 正文平均 | 独立表格块数 | 最大表格长度 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| fixed | 256 | 202 | 115 | 256 | 250.5 | 3 | 860 |
| fixed | 512 | 93 | 77 | 512 | 469.0 | 3 | 860 |
| fixed | 1024 | 46 | 333 | 1024 | 882.8 | 3 | 860 |
| recursive | 512 | 91 | 95 | 512 | 435.9 | 3 | 860 |
| semantic | 512 | 97 | 43 | 512 | 407.1 | 3 | 860 |

复现：将同版本 PDF 保存为实际本地路径，在项目根目录运行以下 Python 代码。使用相同文件字节，避免 arXiv 后续版本造成内容差异。

```python
import hashlib
from pathlib import Path
from statistics import mean
from src.data_loader.pdf_loader import load_pdf
from src.chunking import split_documents

path = Path("data/raw/attention.pdf")  # 替换为实际样本路径。
assert hashlib.sha256(path.read_bytes()).hexdigest() == "bdfaa68d8984f0dc02beaca527b76f207d99b666d31d1da728ee0728182df697"
documents = load_pdf(path)
for strategy in ("fixed", "recursive", "semantic"):
    # 仅固定切分比较三档；另外两种传 None，使用 YAML 默认大小。
    sizes = (256, 512, 1024) if strategy == "fixed" else (None,)
    for size in sizes:
        chunks = split_documents(documents, strategy=strategy, chunk_size=size)
        actual_size = chunks[0].metadata["chunk_size"]
        lengths = [len(c.page_content) for c in chunks if c.metadata.get("chunk_preserved") != "table"]
        tables = [len(c.page_content) for c in chunks if c.metadata.get("chunk_preserved") == "table"]
        assert max(lengths) <= actual_size
        print(strategy, actual_size, len(lengths), min(lengths), max(lengths),
              round(mean(lengths), 1), len(tables), max(tables))
```

## 3 结果与选择

固定策略填充窗口更充分；递归和句段策略为边界保留留下不同长度的块。句段策略是规则切分，不代表嵌入空间中的最佳语义分组。表格保护保持完整结构，但最大表格 860 字符超过 256/512 设置，后续生成层需明确处理上下文预算。

当前 YAML 使用 `recursive`、512/64 作为工程起点，依据是参考项目已使用的算法和现有配置，尚非检索选型结论。下一阶段补充同一组标注问题、Embedding 与检索配置下的 Recall、Hit@5、MRR、检索成功/失败样例及最终选择理由；不填写未运行的质量分数或性能提升。
