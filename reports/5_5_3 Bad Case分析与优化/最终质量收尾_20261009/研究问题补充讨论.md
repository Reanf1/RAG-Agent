# 题型工具选择与实际工具组合

本页在2026年10月9日复算10月7日冻结轨迹，补齐课程研究问题二、三的讨论。原实验、失败题与原始分母不变；不作为本轮rag-v20的质量或性能成绩。复现命令：`python "reports/5_5_3 Bad Case分析与优化/最终质量收尾_20261009/summarize_research.py"`。输入文件哈希及完整计数见[复算结果](研究问题分组复算.json)。

## 哪类题目的工具选择准确率最高、最低

研究问题二使用72题的Agent与固定RAG成对实验。以下仅取其中72条Agent请求，沿用原预先约定的可接受工具路径；失败和无工具回答仍进入分母。

| 题型 | 正确路径／总数 | 工具选择准确率 |
| --- | ---: | ---: |
| 事实 | 14／15 | 93.33% |
| 对比 | 15／15 | 100.00% |
| 归纳 | 12／15 | 80.00% |
| 推理 | 15／15 | 100.00% |
| 概念 | 4／4 | 100.00% |
| 计算 | 4／4 | 100.00% |
| 时间 | 4／4 | 100.00% |

论文题中对比与推理最高，归纳最低；额外三类通用题均为4／4。推理题选对知识库检索路径，并不能证明解释符合论文。归纳题包含未调用工具的失败，概念题则允许直接回答；“无工具”不能一律判错。仅有4条的通用题不足以证明稳定的总体准确率。

另一个60题两组Agent实验中，默认组对比／推理各100%、事实93.33%、归纳80%；关闭规则组推理100%、对比／事实各93.33%、归纳86.67%。两项实验包含重复论文题，分别报告，不合并成更大的独立样本。

## 实际出现了哪些多工具组合

72条Agent路由实验：单次知识库检索54条，无工具7条，计算4条，时间4条，两次知识库检索2条，文献列表后论文对比1条。54+7+4+4+2+1=72。

其中，“知识库检索两次”是同工具多次调用；真正涉及不同工具的组合仅为“文献列表 → 论文对比”1条，占1／72。60题默认组同样仅出现这一个不同工具组合；关闭规则组还出现“知识库检索 → 论文摘要”1条。单次知识库检索是最常见路径，不能称为多工具组合。

本集主要是论文问答，组合样本很少。这说明本次任务多数由一次RAG解决，不能推断真实科研用户普遍最常用什么组合，也不能从这几条自然轨迹推断并行收益。

并行效率仍使用原受控实验：时间／关键词与两个独立知识库问题，每组3对，串并行共12请求。两个知识库问题完整耗时下降18.76%，时间／关键词反而增加2.50%；规划、观察与日志耗时包含在内。自然轨迹频次与受控延迟实验回答不同问题，不混用。

## 对项目的含义

当前保留明确任务路由、独立调用并行及错误恢复即可，不为少量组合添加编排框架。后续质量重点是归纳完整性、问题条件、来源对应和推理依据；工具选择准确率不能替代这几项质量评分。Agent与固定RAG的实际Token增加531.55%的原结论保留，未证明课程给出的节省示例。

## 10月9日rag-v20完整重评的独立观察

本节取[新轮120条原始轨迹](Windows完整重评/agent.json)，不合并10月7日实验。输入指纹与完整工具顺序见[本轮复算](本轮工具路径复算.json)，语义质量见[新轮初评报告](Windows答案助手初评报告.md)。每组仍为事实、对比、归纳、推理各15题；路径指标沿用预定规则，失败仍进入分母。

| 题型 | default正确路径／总数 | no_rules正确路径／总数 |
| --- | ---: | ---: |
| 事实 | 9／15（60.00%） | 11／15（73.33%） |
| 对比 | 13／15（86.67%） | 12／15（80.00%） |
| 归纳 | 6／15（40.00%） | 9／15（60.00%） |
| 推理 | 13／15（86.67%） | 14／15（93.33%） |

默认组对比与推理路径最高，归纳最低；关闭规则组推理最高，归纳仍最低。这里的“路径正确”并不核验最终解释和引用。例如，推理题可以调用知识库后混淆掩码方向。default语义均分1.88／1.55／1.22，no_rules为1.88／1.53／1.15，均不能据路径数字宣称答案合格。

默认组18／60、关闭规则组14／60请求涉及不同工具。两组最多的不同工具组合都是“文献列表＋论文对比”，各8条；只用知识库检索分别34／60和40／60，没有工具分别5／60和4／60。完整调用顺序保留重复调用，组合频次则按每条请求的不同工具集合计数，两种统计不能相加。

组合频次增加也不表示科研能力改善：C013/default的正文证据不足及检索异常，后续关键词／列表成功没有回答论文机制；S005两组只抽取问题关键词；R012/no_rules关键词成功掩盖正文不足。后续补丁已对原轨迹回放阻止误完成，但回放不证明模型生成了正确正文。

本轮只新增两组Agent重新检索与生成，没有固定RAG的成对组，也没有串并行耗时对照。因此，不能重新估算Token节省或并行加速。56次真实并发探针用于定位共享分词器异常，不是性能实验。历史Token增加531.55%、知识库并行下降18.76%和时间／关键词增加2.50%的结论保持原日期及边界；三个研究问题已有实际讨论，但最优参数、泛化质量、成本与最低硬件并未全面证明。
