## 复算与构建

已有模型／论文的实验使用独立目录，以下脚本从归档记录复算；未完成状态会拒绝生成完整成绩图。

```bash
.venv/bin/python "reports/5_5_4 项目交付/verify_experiments.py" chunking
.venv/bin/python "reports/5_5_4 项目交付/verify_experiments.py" routing
.venv/bin/python "reports/5_5_4 项目交付/verify_experiments.py" parallel
```

`plot_delivery.py`按stage绘图；本轮使用新`--source`与`--output`，不覆盖历史图。`verify_container.py`在独立验收容器检查导入／索引／重排／问答／会话重开和外网阻断，I01后最终通过记录为`Windows容器离线验收_20261007/container-7.json`，`container-6.json`保留为前轮记录。

`build_course_report.py`从原模板副本生成Word与实际目录页号；`build_demo.mjs`通过内置Artifact Tool生成原生可编辑图表与表格，旧`build_demo.cjs`保留为历史构建。`audit_delivery.py`核对原件、实验、部署及版式；最终构建拒绝未完成输入。作者工具和资源采样依赖不写入业务requirements，资源采样单独见`requirements-evaluation.txt`。旧668项／183项日志为历史阶段，777项为SSH集中阶段，最新两端780项回归在上方。
