## 如何运行

从项目根目录执行。目录含空格时，脚本路径必须加引号；测试中的跨脚本导入使用标准库`importlib`按实际目录定位。

```bash
# 自动化回归，无需启动Ollama。
.venv/bin/python reports/模块完整性验证/verify_completeness_tests.py --scope all --output reports/模块完整性验证/全量回归_新时间.json

# 三档检索实验：先准备固定论文开发集、本地M3E和BGE；使用新的输出文件。
.venv/bin/python "reports/5_1_4 混合检索与重排序/compare_retrieval.py" --runs 3 --output "reports/5_1_4 混合检索与重排序/检索对比_新时间.json"

# 真实四模块页面联调：需先启动本地Ollama；测试目录与输出必须不存在。
.venv/bin/python reports/模块完整性验证/verify_modules_one_to_four.py --root /private/tmp/rag-modules-新时间 --output reports/模块完整性验证/四模块联调_新时间.json
```

不同脚本所需的权重、论文、可选实验依赖及参数见其`--help`和对应QA。部分数据准备/绘图脚本没有CLI参数；运行前先阅读本节说明。复测始终使用新输出路径，保留首次失败及原始答案；绘图/评分脚本可能更新指定结果，先核对其作用。
