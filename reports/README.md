## 数据集准备

确定研究方向，准备 10–20 篇论文，然后构建至少 50 条问题，覆盖事实、对比、归纳和推理四类。每条记录建议包含问题标识、类型、问题、参考答案、相关文档和可定位来源；实际字段在评测代码实现时统一。
