## 一 项目概述

### 1.1 项目背景

科研人员需要从大量专业文献中快速获取可靠信息，通用大模型对私有论文和最新研究的掌握有限，回答也可能缺少依据。本项目以本地论文知识库为数据基础，通过检索增强生成提供可追溯问答，并由 Agent 调用检索、摘要、对比等工具，探索多步科研任务的辅助流程。

### 1.2 项目目标

实现文献导入、检索、带引用生成与工具决策，完成前端集成、质量评测和可复现交付。实际完成范围待开发后更新。

### 1.3 技术栈概览

参考 [技术设计文档](技术设计文档.md)，提交时补充最终选型、具体版本和原因。
