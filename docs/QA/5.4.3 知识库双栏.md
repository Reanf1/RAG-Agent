# 5.4.3 知识库双栏

2026年10月4日，将侧栏“知识库文档”迁入主工作台第四个“知识库”标签，位于“检索文档”右侧。侧栏继续提供系统状态、文档上传和会话管理。

## 界面与读取

- 左列为文件列表：文件名可点击且选中项高亮，下方显示完整64位文档ID。文件名允许换行，原有行内删除、确认/取消、列表下方刷新及“已归档知识”选择恢复一并迁入。
- 右列直接调用模块一加载器读取所选原文的完整解析内容，不使用Top-K检索片段、模型摘要或重新向量化。PDF保留物理页与独立表格页范围，Word展示段落与表格，TXT/Markdown展示正文，Markdown标题和表格正常渲染。
- 删除当前所选文档后自动选择剩余首份文档；无文档时提示上传。恢复后选中该文件。内容ID无效、原文缺失、指纹变化或解析失败时明确提示，不能冒充原文展示索引片段。
- 知识库汇总面板放在本标签底部；检索标签继续提供Top-K查询与检索分数统计。

复用固定参考前端的Streamlit组件与会话状态方式；上游没有该原文浏览界面，因此在现有布局中适配，不新增服务。全文展示遵循已有加载器能力，属于解析内容视图，不复刻PDF原版排版、不新增OCR，图像及二维公式仍应按原PDF核对。

## 验证

1. 四标签验收修改前实际失败（旧页面只有三个标签），见修改前复现日志。
2. 五个测试文件125项回归通过，包括多格式完整原文读取、指纹/路径/符号链接边界、两文档切换、删除/恢复后的选中状态、原有导入、检索、流式问答、会话、轨迹指标和健康检查。
3. 初次文档流程回归有4处旧检索断言检查了全页面错误。索引测试样例没有原文，新知识库正确显示缺失提示；改为检查“检索文档”标签自身错误，保留知识库的缺失提示。
4. 实际浏览器验证Markdown标题/表格、TXT切换、标签保留、行内删除确认和取消。窄窗口暴露操作列挤压问题，修正列宽、文件名换行及实际CSS类名后，删除/确认/取消均保持54×40像素；布局修正后文档流程32项再次通过。

浏览器和测试只使用临时原文、Chroma、SQLite、测试向量及模拟健康状态，禁止本地生成模型连接；不作为Windows真实性能或模型验收。Windows需要同步代码并重启Streamlit。
