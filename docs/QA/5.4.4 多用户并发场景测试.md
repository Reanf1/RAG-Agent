# 5.4.4 多用户并发场景测试

测试日期：2026 年 10 月 3 日。结论：本机小规模并发下，会话隔离、共享检索、SQLite保存与请求日志核验通过；答案任务为6/7完成，其中一条论文回答因引用格式错误被标记为未完成。不能将本轮写为全部答案质量通过或生产容量达标。

## 1. 范围与方法

- 沿用固定参考仓库的SQLite/Message及隔离模型HTTP测试方式，阅读`app/core/memory.py`、`tests/test_memory.py`；没有添加服务、登录系统或压测框架。
- macOS ARM64，项目Python 3.10.10；实际使用本地Qwen2.5:7b（Q4_K_M）、M3E、BGE reranker-base与Chroma，模型配置不变，禁用自动下载及云端切换。
- 复用上一项真实完整流程的Attention论文原文及94块索引，复制到两个新的临时测试目录；本轮没有重复做上传/索引构建实验。索引元数据保留上一项真实原文路径，原文件仍存在。
- 后端采用真实线程与屏障同时调用`run_session`，每个请求独立user_id/session_id，共享论文索引及SQLite文件。先加载M3E/BGE，加载耗时2.230秒单列；生成模型首组请求包含模型启动/排队等待。不是冷启动并发模型加载实验。
- 三用户历史组明确注入各自随机测试代号的一轮历史，`tools=[]`限定验证记忆；论文组使用默认工具注册、真实混合检索与模型重排；浏览器组使用默认八工具注册和原Streamlit业务页面，两个独立访客会话先存一轮测试历史，然后通过页面同时追问。
- 请求同时处于应用执行区间才算并发；不以开启线程数或页面数代替证据。Ollama原始日志显示`n_seq_max = 1`，生成计算可排队，应用请求重叠不等于模型同时推理。

10项落盘核验全部通过：应用请求重叠；事件/历史归属；5条后端最终日志归属唯一；SQLite历史与事件一致；跨用户访问拒绝；两次RAG均返回5个真实块；共享索引正文/元数据不变；业务配置、默认会话库存在状态与索引ID不变；浏览器答案/历史归属；浏览器请求区间重叠。30条Agent阶段日志和2条RAG日志均可解析，没有数据库锁定错误、半轮历史、重复最终日志或`log_error`。候选均非空不代表Hit@5或答案正确。

## 3. 失败与边界

1. 论文多头注意力问题实际生成了8个头、64维，但正文写成`[参考文档1 - attention.pdf；原始块位置: 第5页（物理页码）]`，没有按约定写`[参考文档1]`。仅来源列表里的编号不计正文引用，因此知识库工具返回`insufficient_evidence`、`missing_citations=true`，Agent最终为`incomplete`。检索、工具执行及保存成功，不能将答案任务计为完成；并发是发生背景，未证实是引用错误的原因。本轮未修改引用解析器来迁就模型输出。
2. 首次核验脚本末尾误将Agent日志的`event`读为`status`，产生`KeyError`，原始运行日志与此前逐事件保存的JSON不覆盖。已修正脚本，并补只读证据核验器，从实际SQLite和原始JSONL重新核验，不重新请求模型来替换失败答案；RAG结束状态核对为`completed/incomplete`。最终报告分别提供`concurrency_checks_passed=true`和`all_answer_tasks_completed=false`。
3. 编码器问题内部RAG依旧同时引用Encoder与Decoder同页片段，上一项细粒度引用Bad Case没有被本轮并发核验消除。
4. 本机随机访客地址标识不是登录认证；共享知识库、单进程日志锁的边界不变。未测试公开部署、10人以上持续负载、并发导入/删除、同一会话同时生成、冷启动同时加载或故障压力。未测最大容量与P95，不为小样本补造统计。

## 4. 自动化回归与修改

新增1项`TestSessionIsolation.test_concurrent_agent_requests_keep_model_context_history_and_logs_owned`：真实Agent循环、SQLite、线程、Token词表及JSONL；仅模型HTTP为明确构造的响应，两次模型阶段均用屏障要求两用户同时到达。验证模型请求只带本用户代号、问答完整追加、独立request_id、日志归属/顺序与Token快照一致。

全项目631项通过（42.127秒）：检索200、生成126、Agent305。专项1项通过（0.189秒）。脚本语法检查通过。业务模块本轮没有修改。

测试页面启动器改为进程内一次安装临时配置，避免多个Streamlit重跑分别进入/退出全局patch而互相还原路径；不替换业务模型、检索或SQLite。两个浏览器实际并发和刷新已验证这个启动器。测试服务及临时标签验证后关闭，临时数据与失败证据保留。
