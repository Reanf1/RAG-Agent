# 5.4.3 前端与会话管理

## 当前布局

侧栏依次为系统状态、文档上传与管理、对话历史管理；主区保留标题／简介和“科研对话、文档检索、知识库”三个标签。独立单轮RAG、课程资料、模块开发状态及评阅说明已移除。

| 区域 | 当前行为 |
| --- | --- |
| 上传 | “上传文档”，开始导入／重试失败项同行；开始后显示进度及成功／失败，成功文件清出选择区 |
| 科研对话 | 460px内部滚动，每轮独立边框；消息框内发送后清空，运行转圈／流式，页脚显示本轮Token／耗时 |
| 决策展示 | 输入下逐轮七列表格，去除轨迹图，状态统计累积当前会话 |
| 文档检索 | 检索方式／Top-k／文档ID同行，查询另起一行；四种检索只返回原文块，保留日志分数分布 |
| 知识库 | 左600px滚动文件列表，右完整解析原文滚动；PDF物理页、Word正文／表格、Markdown原文，不是模型摘要 |
| 文档操作 | 行旁删除，原位同尺寸确认／取消；列表下刷新；“已归档知识”不可编辑选择文件名＋ID，点击恢复实际重建索引 |
| 管理面板 | 直接显示文件名、文档ID、原文状态、向量化状态、索引块数五列，不显示本页批次预期块或错误 |
| 历史会话 | 新建；“最近”标题直接点击并高亮；删除当前会话原位确认／取消，切换恢复按钮；“恢复会话”选择后恢复 |

页面展示的ID均为前八位，与ID标签同行；内部保留完整指纹。八位前缀只用于显示和唯一文档筛选，歧义不能选错文献。

## 数据与持久化

共享知识库按内容指纹汇总，“已向量化”仅表示存在块，不保证全量导入。删除移除检索块，原文进入本地回收目录，历史与日志保留；原文缺失时拒绝回收操作。恢复不覆盖已重新上传同ID原文，失败保留并可重试。

会话操作调用MemoryManager，问答／引用／轨迹／指标存SQLite，删除为归档、恢复保持原ID。切换清空草稿、删除确认和候选确认；保留访客URL可刷新找回演示历史。历史缺失指标显示未知，保存失败明确提示。

PDF来源按钮按原文件指纹与物理页打开，并提供原PDF下载；原文丢失／变化明确报错。候选确认和缓存接入见[5.2.3](5.2.3%20缓存与降级策略.md)。

实现：[app.py](../../src/frontend/app.py)、[组件目录](../../src/frontend/components/)。旧版截图仅是当时证据，最新布局与各次验证合并在[前端验证记录](../../reports/5_4_3%20前端与会话管理/验证记录.md)；Windows2026-10-05[页面复测](../../reports/5_4_4%20端到端联调与测试/Windows浏览器复测_20261005/Windows浏览器复测报告.md)已核验三标签、上传清空、行内删除/取消与恢复、滚动历史/知识库布局；三侧栏标题均20px，删除/确认/取消均54×40px。业务任务与引用仍有缺陷，布局通过不等于整体验收通过。
