# 5.3.3 路由并行与错误恢复

> 状态口径（2026-10-09）：当前实现与验收以[技术设计](../%E6%8A%80%E6%9C%AF%E8%AE%BE%E8%AE%A1%E6%96%87%E6%A1%A3.md)为准。带日期的实验数值、截图和“本轮／待完成”描述属于对应历史阶段；自动回归、真实链路、助手初评与用户审核分别记录，局部复测不替代完整题集。Word／PPT保留10月7日快照，按用户安排待结论确定后重建。

## 路由与独立并行

明确算式、时间、列表、单篇摘要／元信息／对比、本地知识或联网任务走快速规则，复合／依赖／不确定意图交给Thought规划。显式工具名与其他语义意图取并集，不能因出现`keyword_extract`就漏掉“当前时间”；R01修复回归已通过，10月7日真实串并行实验已单独完成。

同轮最多2个独立调用／线程；允许同名工具不同参数，相同参数重复拒绝。结果按调用ID关联整批ToolMessage，避免只反馈最后一项。依赖前一步结果的调用不得并行，本地Ollama排队仍可能限制收益。

## 错误恢复与终止

工具总逻辑等待预算300秒、最多重试1次。只重试已结束的真实超时异常；仍在线程中运行的调用不重复启动。超时／异常记录错误并按可用工具与来源约束尝试替代或跳过；最新外部任务不能静默用旧本地文献替代。

相同工具参数最多2轮，交替重复／无进展和8轮上限均有强制终止提示。Python线程无法强杀，超时表示停止等待，不承诺底层函数已停止或副作用回滚。

实现：[router.py](../../src/agent/router.py)、[react_loop.py](../../src/agent/react_loop.py)。超时注入、异常替代、重复及独立并行的实际／mock证据分别保留在[5.3.3目录](../../reports/5_3_3%20Agent决策优化/README.md)。研究问题三已有10月7日12条实际对照：知识库组合下降18.76%，时间／关键词组合增加2.50%，各3对，不声称所有任务均提速。两篇分别处理的同名批次现在要求两次独立调用、覆盖本轮两个真实ID；Observation在缺任一结果时不得宣称完成。
