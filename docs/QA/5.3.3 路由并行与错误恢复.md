# 5.3.3 路由并行与错误恢复

## 路由与独立并行

明确算式、时间、列表、单篇摘要／元信息／对比、本地知识或联网任务走快速规则，复合／依赖／不确定意图交给Thought规划。显式工具名与其他语义意图取并集，不能因出现`keyword_extract`就漏掉“当前时间”；R01修复回归已通过，真实串并行实验未重跑。

同轮最多2个独立调用／线程；允许同名工具不同参数，相同参数重复拒绝。结果按调用ID关联整批ToolMessage，避免只反馈最后一项。依赖前一步结果的调用不得并行，本地Ollama排队仍可能限制收益。

## 错误恢复与终止

工具总逻辑等待预算300秒、最多重试1次。只重试已结束的真实超时异常；仍在线程中运行的调用不重复启动。超时／异常记录错误并按可用工具与来源约束尝试替代或跳过；最新外部任务不能静默用旧本地文献替代。

相同工具参数最多2轮，交替重复／无进展和8轮上限均有强制终止提示。Python线程无法强杀，超时表示停止等待，不承诺底层函数已停止或副作用回滚。

实现：[router.py](../../src/agent/router.py)、[react_loop.py](../../src/agent/react_loop.py)。超时注入、异常替代、重复及独立并行的实际／mock证据分别保留在[5.3.3目录](../../reports/5_3_3%20Agent决策优化/README.md)。研究问题三的完整串并行对照仍为3/12暂停，不能宣称已经证明提速。
