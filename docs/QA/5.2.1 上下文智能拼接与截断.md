## 1. 参考源码与适配

实现前阅读固定版本的 [RAGEngine.build_context()](https://github.com/dsy1018/ai-chatbot/blob/6979d7173ed0f92910a8571dd4ca1b4a171a2c49/app/core/rag.py)、[TestContextBuilding](https://github.com/dsy1018/ai-chatbot/blob/6979d7173ed0f92910a8571dd4ca1b4a171a2c49/tests/test_rag.py) 和 [metrics.py](https://github.com/dsy1018/ai-chatbot/blob/6979d7173ed0f92910a8571dd4ca1b4a171a2c49/app/core/metrics.py)。上游按重排后的顺序拼接全部文本，使用 `[参考文档N - 来源: 文件名]` 和 `\n\n---\n\n`，返回 `context`、`sources`、`chunk_count`；没有上下文预算或动态截断。其指标模块使用 GPT 模型编码器估算 Token，不直接作为本项目 Qwen 的精确计数。

本项目保留 Context 字典、编号与分隔符，增加按同一路检索分数排序、真实位置、字符预算、截断与遗漏标记。不新增检索器、模型权重、依赖或服务，也不在本次实现完整 LLM 流水线。

## 2. 排序和动态预算

输入为 `list[tuple[Document, float]]`，兼容向量、BM25、RRF 或模型重排的结果。分数降序，同分保持原顺序，负分保留；不能把不同检索方式的分数混在一起排序。非有限分数报错，空白正文跳过，不设置未经评测的相关性阈值。

配置统一读取 [config.yaml](../../config.yaml)：

```yaml
generation:
  max_context_chars: 6000
  max_prompt_chars: 12000
```

先通过真实 Prompt 模板计算系统规范、问题和两部分标签的字符开销，再确定本轮上下文余量：

```text
固定开销 = 系统消息字符数 + 用户消息中除上下文外的字符数
上下文预算 = min(max_context_chars, max_prompt_chars - 固定开销)
```

问题变长或系统规范增加，文档预算相应减少。默认上限是教学起点，不是性能选型结论。计数包含上下文的来源标题、正文、分隔符和截断提示；Prompt 总长度是两条消息内容的字符数，不含聊天协议、历史消息、工具描述或生成回答。Python 字符切片不会切断 Unicode 码点，但字符数不等于 Token 数；LLM 接入时仍须按实际模型编码器、协议和输出预留核验窗口，不能直接把 12000 当作模型的 `num_ctx`。

## 3. 截断与来源规则

按排序依次尝试加入文档块：完整块能放下则保留原文；正文超长时保留预算内的前缀，尽量在可用前缀后半段的段落或句末结束，追加 `[正文已截断]`。没有合适自然边界时按字符截断，不生成摘要或改写事实。

来源标题必须完整，并且至少保留非空白正文。标题过长或剩余空间不足时跳过该块，继续尝试后续块；编号只为实际入选的块连续分配。`sources` 只包含入选块的真实文件名，按出现顺序去重；被省略文档不列为来源。

标题记录“原始块位置”：PDF 使用物理页码/跨页范围，Word 使用段落或表格位置，TXT/Markdown 使用行范围。缺少元数据明确写“来源信息未提供”或“位置未记录”，不伪造页码。截断后的前缀仍对应原始块范围，不宣称已定位到更精确的截断终点；原 Document、块 ID、元数据及输入顺序均不修改。

无有效正文返回空 Context，沿用既有 Prompt 的无相关文档提示。问题与系统规范已超过总预算，或有有效证据却连来源和正文都放不下时，明确抛出 `ValueError`；预算不足不能伪装成检索无结果。

## 4. 接口与调用

```python
from src.retrieval.hybrid_retriever import HybridRetriever
from src.generation.rag_pipeline import build_context
from src.generation.prompt_template import build_rag_messages

# 使用现有本地索引和模型；本示例只组织消息，尚不生成答案。
question = "Transformer 的编码器使用什么结构？"
results = HybridRetriever().search(question, k=5, rerank=True)
context = build_context(question, results)
messages = build_rag_messages(question, context["context"])
print(context)
```

| 返回字段 | 含义 |
| --- | --- |
| `context`、`sources`、`chunk_count` | 已拼接文本、实际入选文件名、入选块数，沿用参考项目 |
| `context_budget_chars`、`context_chars` | 本轮动态预算、上下文实际字符数 |
| `prompt_chars` | 模板消息内容的总字符数，不是 Token 消耗 |
| `truncated` | 存在正文截断或非空候选被省略；仅省略时未必有正文截断标记 |
| `dropped_count` | 被预算省略的非空候选数；空白正文不计入 |
