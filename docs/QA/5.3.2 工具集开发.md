## 八个本地工具

使用LangChain `@tool`与简单注册列表，不建插件框架。论文ID均为已上传文件真实SHA-256，字段缺失明确资料不足。

| 工具 | 输入 | 输出与范围 |
| --- | --- | --- |
| knowledge_base_search | question、可选doc_id | 模块二RAG、答案／来源／分数／实际用量；缓存与候选确认见5.2.3 |
| paper_metadata | doc_id | 标题、作者、年份、摘要、DOI及逐字段原文位置；前三页／6000字符预算 |
| paper_compare | 两个不同doc_id | 方法、数据集、实验结果的原文证据对照；各论文／维度分配预算与检索，不自由改写实验数字 |
| keyword_extract | text或doc_id二选一 | 最多5个匹配原词的中英文关键词与来源；不扩展同义词 |
| paper_summary | doc_id | 背景、方法、结果、结论四栏中文摘要和实际引用；可直接读原文，不要求已有索引 |
| current_time | 无 | 运行机器ISO8601时间与时区偏移，零模型调用 |
| calculator | expression | 受限AST＋28位有效数字Decimal四则运算，小数／负数／括号，不执行任意代码 |
| paper_list | 无 | 文件名、真实ID、实际块数、原文及索引状态；空库不为列表创建数据库 |

元信息模型只提取四个短字段并匹配原文，摘要按标题边界提取。同行`Abstract.`／`Abstract:`后的第一句保留，不含后续正文；缺项为null／空作者数组，不联网补全。摘要优先摘要／结论段，剩余按原文顺序补预算，一次结构化生成，每栏来源编号校验；缺项返回insufficient_evidence。

对比工具按方法／数据集／结果分别召回、去重、重排；两篇同等预算，低相关维度标注，缺一篇证据不生成。工具成功、字段齐备及编号合法均不保证科学内容正确。

## 可选联网搜索

`web_search`为额外第9个工具，默认`agent.online_search_enabled=false`，注册与执行均校验。启用后DuckDuckGo HTML经httpx／BeautifulSoup取最多5条标题、摘要、URL，15秒超时，解包uddg，不读取网页全文、不编本地页码。搜索词外发，应避免将私有原文与历史作为查询。

真实搜索曾遇验证页，未知HTML／HTTP／网络错误明确失败；解析mock通过不证明线上服务可用。八个本地工具不依赖它。
