# 5.4.3 工作台三标签

2026年10月4日，按用户要求整理主工作台，保留“智能科研助理”与副标题“基于 RAG + Agent 的论文知识库问答系统”。删除顶部上传/增量索引说明、“科研对话”标题、模块开发状态表和评阅说明。

## 三个入口

| 标签 | 对应能力 | 保留内容 |
| --- | --- | --- |
| 单轮对话 | 现有RAG独立问答，历史只展示、不进入推理上下文 | 缓存、流式输出、真实引用、低相关确认、错误提示、清空历史、RAG运行指标 |
| 多轮对话 | 现有Agent和SQLite会话记忆 | 历史追问、工具调用、流式答案、来源入口、公开决策轨迹与Token/工具指标 |
| 检索文档 | 现有文档检索与知识库详情 | 知识库管理面板、向量/BM25/RRF/模型重排Top-K检索、原文位置、检索分数分布 |

相应指标、错误提示和查询结果都在对应标签内部展示，主区域不再将不同工作区内容串联堆放。功能实现、会话存储和检索算法沿用现有代码，不新增服务或前端框架。

- 修改前复查固定参考前端的主对话区、历史渲染和输入处理；沿用Streamlit组件和会话状态，本项目三类工作区是现有能力的界面归组。
