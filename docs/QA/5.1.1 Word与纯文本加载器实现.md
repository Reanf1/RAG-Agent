# 5.1.1 Word 与纯文本加载器实现

实现与验证日期：2026 年 9 月 29 日。

## 1 实现范围与参考依据

- [docx_loader.py](../../src/data_loader/docx_loader.py)：使用 `python-docx==1.1.2`，读取 `.docx` 正文段落及顶层表格。
- [text_loader.py](../../src/data_loader/text_loader.py)：使用标准库读取 `.txt`、`.md`、`.markdown`，保留纯文本原文。

沿用固定参考仓库 [RAG 源码](https://github.com/dsy1018/ai-chatbot/blob/6979d7173ed0f92910a8571dd4ca1b4a171a2c49/app/core/rag.py) 的“路径 → Document 列表”、文件存在与格式校验、来源字段。本项目按课程要求用 python-docx 替代上游 Docx2txtLoader；Markdown 按用户要求当纯文本处理，不引入 UnstructuredMarkdownLoader 或渲染库。

Word 使用 `iter_inner_content()` 按正文中段落/表格的先后顺序读取，避免先读所有段落、再追加全部表格导致顺序错乱。该方法在使用的 [python-docx 1.1.2 源码](https://github.com/python-openxml/python-docx/blob/v1.1.2/src/docx/document.py) 中提供，含义见 [官方 Document 文档](https://python-docx.readthedocs.io/en/latest/api/document.html#docx.document.Document.iter_inner_content)。

UTF-8 BOM 用 `utf-8-sig` 解码移除，其他正文字符保留，不尝试猜测编码；该解码行为见 [Python 官方编码说明](https://docs.python.org/3/library/codecs.html#encodings-and-unicode)。

## 2 接口和位置元数据

```python
from src.data_loader.docx_loader import load_docx
from src.data_loader.text_loader import load_text

# Word 按段落/表格返回，TXT/Markdown 整篇返回，均为 Document 列表。
word_documents = load_docx("docs/项目交付模板.docx")
text_documents = load_text("README.md")
```

两种加载器均保留 `source`（绝对路径）、`source_file`、小写 `file_type`、`doc_id`（原文件字节的 SHA-256）。同文件所有返回块共享 ID，重复读取稳定，文件内容变化后 ID 更新。格式扩展名不区分大小写，接受 `str` 和 `Path` 输入。

| 格式 | 返回方式 | 位置字段 |
| --- | --- | --- |
| DOCX 段落 | 每个非空正文段落一个 Document，去除首尾空白 | `block_type=paragraph`、`block_index`、`paragraph_index` |
| DOCX 表格 | 每个非空顶层表格一个 Document，行间换行、单元格间制表符 | `block_type=table`、`block_index`、`table_index` |
| TXT/Markdown | 整篇一个 Document，保留原始缩进与换行，后续另行分块 | `line_start=1`、`line_end` 为正文总行数 |

Word 所有位置编号从 1 开始；`block_index` 同时计入段落和表格，另外两种序号分别计数。空块跳过但不重新编号。TXT/Markdown 行数按 `splitlines()` 计算，末尾换行不额外算一行。当前整篇的行范围不能直接当作以后每个分块的精确引用位置，分块模块需继续维护位置。

## 3 已处理情况与边界

- 缺失文件或目录输入：`FileNotFoundError`。
- 格式不符合对应加载器：`ValueError`；旧版 `.doc` 需先转换成 `.docx`。
- Word 没有可提取正文/表格文本、TXT/Markdown 为空或仅空白：`ValueError`。
- 损坏 Word：原生解析异常向上传递；非 UTF-8 纯文本：`UnicodeDecodeError` 向上传递，转换为 UTF-8 后再导入，不静默丢弃字符。
- Word 不生成物理页码，只提供原始段落/表格位置。本轮不提取页眉页脚、修订、文本框、图片或嵌套表格。
- 表格保留单元格文本和空单元格分隔符，不还原样式或复杂结构；合并单元格按库的网格展开，可能重复文本。
- Markdown 不转换标题、链接、代码块或表格语法，也不读取链接目标；UTF-8 BOM 被去除，CRLF 换行及代码缩进保留。
