# 5.4.3 科研对话交互与累计状态

## 本次范围

按用户七项要求，工作台保留科研对话、文档检索、知识库三个标签。删除独立单轮RAG的页面、缓存/确认交互和对应UI测试；模块二生成、缓存、降级、引用及日志接口和核心测试保留，旧SQLite数据不删除。

## 页面行为

- 科研对话采用460像素高的边框容器，消息内部滚动、增量自动滚到最新内容；每轮用户/Agent消息另有独立边框。
- 原生消息框内显示“发送”，点击或Enter提交后自动清空；输入框按会话设置key，切换后不会沿用其他会话草稿。
- 运行期间显示“正在处理…”和转圈；Agent正文逐包更新，同时刷新输入框下的执行表。完成后重绘历史与侧栏标题，不再次调用模型。
- 每轮回答页脚显示本次Token、Agent响应耗时与来源按钮；输入框下按该轮问题展示执行表，最新轮默认展开，旧轮可展开。七列为阶段、轮次、工具、输入Token、输出Token、耗时、状态；移除轨迹图、原始JSON和原逐阶段长说明。
- 成功/失败按真实阶段与工具结果展示。运行时尚未返回的工具暂标执行中；流结束仍未取得结果标失败，原始pending记录保留，不冒充已返回调用。
- 前端断流保留部分回答、失败原因及最终失败快照，存入SQLite后切回会话仍可查看。数据库保存失败会另行提示。

## 状态统计口径

统计当前会话的每轮最终快照，切换会话随之切换，普通重绘不重复累计。卡片为对话次数、累计Token、累计响应耗时、平均响应耗时、任务完成率、工具调用次数、工具成功率、平均推理轮次；另显示RAG检索次数、候选命中率、平均检索/工具耗时和成功/失败/待返回数量。

并行共享Action只计一次模型用量，各工具内部用量单独归属。规则与无模型工具只有实际报告为0才显示0；缺失显示未知。旧历史有任一未知Token或耗时，则完整累计量显示未知，已知Token另列；平均耗时只基于已报告样本。任务完成率仅统计保存了布尔完成状态的轮次，工具成功率仅以已返回调用为分母。运行候选命中率为有候选的已完成检索占比，不等于评测Hit@5或答案正确率。
