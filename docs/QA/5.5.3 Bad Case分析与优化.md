# 5.5.3 Bad Case分析与优化

完成日期：2026-10-04（模型实测跨10-03～10-04）。基于用户刚完成的5.5.2，使用默认60题基线，不改金标准、不替用户填写人工评分。

## 实现与依据

阅读固定上游[Agent源码](https://github.com/dsy1018/ai-chatbot/blob/6979d7173ed0f92910a8571dd4ca1b4a171a2c49/app/core/agent.py)及[工具测试](https://github.com/dsy1018/ai-chatbot/blob/6979d7173ed0f92910a8571dd4ca1b4a171a2c49/tests/test_tools.py)。沿用实际工具执行、ToolMessage与HTTP隔离测试；上游一轮调用没有本项目论文ID/多轮来源交接约束，本轮在既有手写ReAct中补充，保持目录与接口。

业务只在`src/agent/react_loop.py`补充39行：论文主工具缺ID先取列表；从成功列表解析唯一文件名/干名为真实ID；单次RAG完整回答原问题、grounded/answered/有效引用且Observation确认完成时原样保留答案。歧义/未知名称、失败列表、子问题、多工具、低相关确认、证据不足与未完成判断不直接替换。保留真实模型用量，不跳过决策或补造引用。

## 实测与验证

- 四类非互斥，归档10个原文复核代表例与全部60题风险索引。20题未命中标注页、37题目标论文覆盖不全属于自动风险；F005第5页/F010其他论文也有等价事实，不能把页漏命中当语义检索失败，不反改标注抬高分数。
- 新11项回归修复前4项失败、修复后通过。随后完整654项通过（43.662秒），无失败/错误/跳过。mock不计模型质量成绩。
- 完整后测60题、283次实际LLM响应，与基线默认60题/311次对照：路径准确率81.67%→88.33%，轮次1.5833→1.3833，Token均值14506.40→12956.15（下降10.69%）；时延44.2640→47.6983秒（增加7.76%）。
- 无效必填ID15→0；工具失败16→5；重复终止5→0。条件来源文本原样保留0/22→22/22；共同合格21题由0/21→21/21。此指标不是语义引用准确率。
- 独立复核确认旧基线/输入未覆盖、配置与模型摘要一致、只一个业务文件变化、完整60题、实际用量及汇总正确。Qwen模型seed20261003，采样/检索参数不变；无云端调用。

## 残留与结论范围

C006先列表时仍产生未声明参数；C015真实对比成功却回答错误字段且明显变慢；S009选了合法但错误的DETR过滤范围；S002变为Action错误；S013同名检索计划仍失败。F002误拒答、F005一般概念误路由、R001主语/因果与R015数据条件错误仍存在。迭代实现并验证结构收益，不代表所有质量或效率目标达标。

所有原文英文、开发集选择优化、单遍前后执行顺序与缓存热态有差异；页级标注不穷尽事实。人工评分仍待回传。检索代码未变，本轮未重复五组独立检索，不能声称检索后测改善。

样例准备时曾误以为metrics.trace包含最终answer，正式样例改从同一row.answer读取；保留准备失败日志，不把它计为业务复现故障。正式修复前11项中4项失败证据保留。首次643项发现未含新小节，随后补包入口并完成654项；旧643日志另存。首次绘图使用临时Matplotlib缓存，之后指定可写缓存目录，最终图已检查。
