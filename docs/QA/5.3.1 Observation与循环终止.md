## 1 实现与依据

在[react_loop.py](../../src/agent/react_loop.py)增加`observe()`和`run_react()`，把已有Thought与Action串成手写的有界循环，不使用高层Agent执行器，不增加依赖或配置层。

本次核对固定上游[AgentManager源码](https://github.com/dsy1018/ai-chatbot/blob/6979d7173ed0f92910a8571dd4ca1b4a171a2c49/app/core/agent.py)及API事件测试：上游将AIMessage与ToolMessage送回模型生成答案，但只有一轮工具调用。课程要求的继续决策与迭代上限由本项目补充。根据[Ollama官方工具调用文档](https://docs.ollama.com/capabilities/tool-calling)，将AIMessage转换为原生`assistant.tool_calls`，ToolMessage转换为`tool`角色及`tool_name`，把实际结果交给Observation。

一轮流程为：Thought规划 → Action生成参数并实际执行（或跳过）→ Observation观察 → 继续下一轮或结束。观察数据包含真实工具名、参数、成功/失败、结果/错误及耗时；结构化结果保留在Context.observations，关联消息提供给本轮模型。判断进入Context.last_observation，供下一轮Thought读取。输入Context与对外事件使用副本，原始来源不覆盖。

## 2 Observation判断

`observe(question, tools=None, context=None, messages=None)`使用当前本机Ollama与已有采样参数，通过JSON Schema生成并在Python中校验四个字段：

| 字段 | 约束 |
| --- | --- |
| observation | 1～200字符的简短结果/决策说明，不要求私有思维过程 |
| decision | continue或finish |
| task_complete | 布尔值；区分成功完成和结束但未完成 |
| answer | continue时为空；finish时给出最终答案或无法完成的说明 |

工具成功不自动等于完整任务成功，例如乘法得到12后，还需要加5；缺少论文依据可结束并说明资料不足。最后一次工具返回error时，拒绝模型标记成功；可以继续规划其他已有工具，后续实际成功后再判断完成。该检查是保守的失败边界，不能证明模型答案在语义上一定正确，仍需后续质量评测。

输出截断、未完成响应、非法字段/类型、continue同时标记完成、finish却没有回答、工具失败却标记成功均拒绝。各模型事件保留真实输入/输出Token和耗时；未提供的Token为None，不估算。

## 3 循环与终止

`run_react(question, tools=None, context=None)`为事件生成器，持续消费才会推进；每个阶段事件带iteration，最后一个事件为done。关闭生成器后不继续执行未开始的步骤。

| done.stop_reason | 触发条件 | task_complete |
| --- | --- | --- |
| task_complete | Observation为finish且任务完成 | true |
| incomplete | Observation为finish，但资料不足或无法完成 | false |
| max_iterations | 最后一轮仍为continue | false |
| error | 模型/网络/调用协议错误或非法输入 | false |

上限读取`config.yaml`的`agent.max_iterations`，当前8，必须为正整数；一轮包括三个阶段，不按HTTP请求数量计。先判断完成，再检查上限，因此恰好在第8轮完成仍算成功；达到上限时不启动第9轮，不再调用模型/工具，并明确提示缩小问题范围。done还包含full_response、实际iterations与Context快照。判断成功应检查task_complete，不应只检查是否收到done。

工具自身异常作为tool_result交给Observation；模型/协议错误则停止循环并返回error和未完成done。Observation失败时保留已执行的工具结果，不自动重试模型或转云端。

```python
from langchain_core.tools import tool
from src.agent.react_loop import run_react

@tool
def multiply(a: float, b: float) -> float:
    """计算两数乘积。"""
    return a * b

# 需启动本地Ollama；传入的必须是真实工具。
for event in run_react("请用工具计算3乘4。", [multiply]):
    if event["type"] == "done":
        print(event["task_complete"], event["stop_reason"], event["full_response"])
    else:
        print(event["type"], event.get("iteration"))
```
