# 5.3.4 多轮对话记忆管理

## 会话隔离与窗口

SQLite会话ID独立、user_id固定归属；每次独立连接，整轮问答事务保存，跨用户访问拒绝。`run_session()`只读取当前会话历史，新的问题不继承旧工具观察／禁用／恢复状态；关闭生成器不写半轮模型历史。访客地址仅为演示入口，不是账号认证。

`get_context()`用本地Qwen官方tokenizer.json统计历史JSON，预算默认2000 Token。从最旧完整问答对移除，最新单轮超限则窗口为空；数据库原历史保留。缺词表／模型不匹配拒绝执行，不用字符近似或自动联网。预算仅针对摘要＋历史，系统／当前问题／工具结果另占完整模型窗口。

## 阶段性摘要

未压缩历史达到10轮，保留最近4轮，其余连同已有摘要由本地模型压缩，摘要JSON最多400 Token；摘要与最近历史共享2000预算。SQLite记录摘要及已处理消息边界，原文归档不删除。

模型失败、部分响应、超限不覆盖旧摘要，记录警告后使用窗口；超大旧单轮不截断后冒称已处理。每次读取最多3批，剩余旧历史后续继续。写入前校验边界，拒绝并发过期摘要；清空同步删除摘要。记忆摘要用量单独记账，未知不写0。有损压缩不能保证保留每个细节。
