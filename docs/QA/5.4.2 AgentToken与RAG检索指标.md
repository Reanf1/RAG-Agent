## 2. Token记账规则

`run_react`在原有有界循环外增加轻量事件汇总，每个事件携带独立`request_id`和深复制的`metrics`。指标不加入模型Context，也不复用上一请求的账目。

| 阶段 | 统计内容 | 归属方式 |
| --- | --- | --- |
| 记忆摘要 | 本请求新产生的摘要模型用量 | 单列；重用已有摘要不再次收费 |
| Thought | 规划模型的输入/输出Token | 规则路由明确为0 |
| Action | 生成工具名和参数的模型用量 | 单工具关联其调用ID；并行整批共享一次，单列全部ID，不虚构均摊 |
| 工具内部 | 工具返回的usage，例如RAG回答或论文摘要生成 | 按真实工具调用ID分别记录；工具已汇总多次模型调用时使用其汇总值 |
| Observation | 观察结果和继续/结束判断的模型用量 | 单列，不重复归入工具内部 |

请求总量为上述行的输入/输出之和。共享Action后续事件的0用量不新增第二条Action账目。计算器、时间、文献列表等明确不调用模型的工具内部用量为0，其Action和Observation仍可能消耗Token。

缺失、非法用量以及失败/超时/重试中未完整报告的部分保持未知，完整`total`为`null`，同时保留`known_total`（已报告部分）与`unknown_calls`（用量不完整的记录项数）。这个项数不是准确的失败模型调用次数。重试只取得最终工具响应时，不声称此前尝试免费；失败工具内部的部分已消耗Token可能无法恢复。摘要失败也记录一条未知用量尝试，不能因为回退历史窗口而漏记。

`run_session`在每个阶段追加`logs/agent_YYYY-MM-DD.jsonl`，包含请求/用户/会话标识、问题、事件、轮次、用量分项及响应耗时。一个请求有多个阶段快照，汇总时取同一request_id的最新快照，不叠加各快照总量。直接使用无会话`run_react`可取得相同指标事件；持久记录由会话入口负责。日志写入失败随事件明确提示，不破坏已经完成的回答。

## 3. RAG统计口径

运行时缺少问题的人工相关文档标注，因此页面展示的是**候选命中率**：

```text
候选命中率 = 返回非空文档块的检索请求数 / 成功结束检索的请求数
```

成功结束包括非空和空结果；失败单独计数，不进分母。缓存命中和未开始检索均排除。每次RAG工具调用算一个检索请求，不按用户问题去重；同一RAG request_id的检索、等待确认和生成结束快照只计一次。低相关性也可能返回非空候选，因此它可以“候选命中”，同时任务仍待确认。

该比例不是语义相关率、回答正确率或Hit@5。正式Hit@5/MRR/Recall继续使用已标注评测集计算，不以非空结果、重排分数或日志字段代替。没有实际检索样本显示“暂无样本”，不显示虚假的0%。

`retrieval_request_metrics()`复用`read_rag_requests()`读取最新快照，同时统计直接RAG问答和Agent知识库工具：

- 检索延迟：实际检索阶段的`retrieval_seconds`，包含混合检索、重排和上下文准备；实际失败请求也计入耗时。
- RAG响应延迟：RAG请求截至回答、确认提示或终止的处理耗时，含检索与生成，不含用户确认等待；仅完成检索但生成仍在进行的快照不进入响应延迟均值。
- Agent响应耗时：独立从run_session开始计时，包含记忆准备、所有循环阶段及最终问答保存；运行中表示截至当前事件的累计处理时间，done为最终值。

损坏日志行跳过并提示数量，原文件保留。候选命中率/均值是本地运行日志累计统计，Agent分项面板显示当前页面最近一次请求，二者统计范围不同。

知识库工具结果补充`retrieval.request_id/status/returned_chunks`及原有真实耗时，将工具返回与RAG日志关联。工具整体失败而没有返回检索数据时，Agent当前分项显示未知，实际检索失败详情以RAG日志为准。

## 4. 页面和接口

页面新增“RAG运行指标”和“Agent问答与实时指标”。Agent表格展示阶段、轮次、工具、关联调用标识、输入/输出Token和用量完整性。Thought、Action、工具结果、Observation、done完成时刷新同一面板；不是模型尚未返回usage时逐Token估算。

Agent表单复用MemoryManager/run_session，第一次提交才建立本页独立SQLite会话；页面启动不连接或加载模型。浏览器重跑只重绘最近一次快照，不重新执行模型、工具或写日志。页面UUID用于本地会话归属，不等同于登录认证。本次不实现完整轨迹、历史会话切换/删除、工具成功率面板或健康检查，M4-02与M4-05仍部分完成。

调用示例：

```python
from src.agent import MemoryManager, run_session

memory = MemoryManager()
session = memory.create_session("demo")
for event in run_session("用计算器计算3.14乘以2.56", "demo", session, memory=memory):
    # 每个事件有独立快照；total为None时只能报告已知部分。
    print(event["type"], event["metrics"]["tokens"])
```

后续已补齐公开轨迹和工具成功率/耗时面板，当前状态与核验见[轨迹与工具指标QA](5.4.2%20Agent决策轨迹与工具指标.md)；上文“本次不实现”描述本阶段原范围。
