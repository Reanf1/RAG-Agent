统一使用项目已有 `load_pdf()` 和默认递归切分 512/64 字符。本轮不再改变递归或句段策略的参数。候选为六篇完整 PDF 的全部 821 个分块，包括摘要、正文、图表、参考文献和附录；中文论文来源 406 块、英文论文来源 415 块。语言按论文主体划分，中文论文中的英文摘要、图题和参考文献照常保留，不另做逐块语言检测。没有只抽取包含答案的段落，也没有追加与主题无关的随机负例。15 个已识别表格作为整块保留，最长候选 2,431 字符。

## 3 控制变量、指标与选择规则

平台为 Apple M4、16 GiB 内存、macOS Darwin 27.0.0、Python 3.10.10；两个模型统一 CPU、FP32、4 线程、批次 32、最大 512 Token，向量 L2 归一化。使用 `langchain-huggingface 0.1.2`、`sentence-transformers 3.3.1`、`transformers 4.46.3`、`torch 2.5.1`；完整版本写入结果 JSON。只比较纯向量检索，不接 BM25、RRF、Reranker 或 LLM，避免将其它组件的收益算给 Embedding。

- Hit@5：前五项命中至少一个已标注相关块的查询比例。
- Recall@5：每题前五项命中的相关块数除以全部已标注相关块数，再平均。
- MRR@10：前十项第一个相关块的排名倒数；未命中记零，再平均。
- 文档速度：预热后，分别编码中文论文来源和英文论文来源的全部候选，重复三轮；完整库与两种正文语言各记录三轮耗时、中位数及块/秒。
- 查询延迟：每轮逐条编码全部 96 条问题，三轮共 288 次；记录总体和每组的中位数/P95。不是完整问答延迟。

模型以 FP32 推理；SDK 返回的向量转为 NumPy float64，通过显式 `einsum` 点积排序，同分保持候选顺序；检查全部向量和相似度有限、平方范数误差小于 `1e-5`。预热与下载不计入编码耗时；模型加载时间单列，不作为严格冷启动数据。Token 与字符不是同一单位，受保护长表格等超长输入按模型限制截断并如实计数。

**编码前确定的选型规则**：四组等权宏平均 Hit@5 优先；差距不超过 1/96 且宏平均 MRR@10 差不超过 0.03 时，选择更快、更小的模型，否则选择质量领先者。必须同时列出逐组和最差组结果，不能用中文平均分掩盖英文不足。本轮各组题数相同，因此宏平均与全体平均相等；这是工程取舍规则，不是统计显著性检验。

BGE 三轮文档编码秒数：170.747, 172.272, 170.285；M3E：54.797, 54.439, 54.323。两模型均有 5/821 块被截断（约 0.61%）；全部向量/相似度有限，最大平方范数偏差分别为 `3.68e-07`、`2.81e-07`。资源数字是权重磁盘大小，不是峰值内存。

**选择并保留 `moka-ai/m3e-base`。** M3E 共命中 33/96 题，BGE 为 30/96；宏平均 Hit@5 高 3.125 个百分点，MRR@10 也略高。按预定规则 M3E 是本次质量领先者，同时完整库编码约快 3.14 倍，查询中位延迟约快 4.19 倍，权重约少 68.6%。业务仍只加载 M3E，不引入按语言切换两模型的路由。

这个选择有明确取舍：M3E 的英文同语言检索为 13/24，BGE 为 10/24；中文同语言检索反而从 BGE 的 15/24 降到 M3E 的 14/24。英文查中文只有 M3E 1/24、BGE 2/24，M3E 的最差组更差；中文查英文也只有 M3E 5/24、BGE 3/24。**两者都不能据此宣称满足可靠的跨语言论文检索要求。** 宏平均领先仅用于当前两个候选中的工程选择；不把小样本差距解释为显著优势。

以下是 M3E 原始排名中的跨语言未命中例子（“未命中”指没有召回已标注目标块，不是模型生成了错误答案）：

| --- | --- | --- |
| `attention-02-zh` | attention PDF第5页/候选28 | vision_survey PDF第5页/候选27 |
| `cnn_survey-01-en` | cnn_survey PDF第8页/候选40、cnn_survey PDF第4页/候选23 | vision_survey PDF第21页/候选140 |

完整问题和标注见评测集，完整排名见结果 JSON。示例显示返回了其它论文来源；语言影响和输入噪声属于待排查因素，具体根因仍需人工查看原页、分块及其它可能相关段落后确认。

## 5 限制与后续使用

这是六篇人工智能论文上的开发选型基准，**不代表任意中英文论文或跨语言检索均已达标**。事实、参数和方法解释题多于开放式多论文归纳题；标注以指定来源为准，不评测生成答案的正确性和引用质量。两模型均有语言覆盖限制，不因选定其中一个就认定双语质量要求完成。

原文保留全角字符、公式标记、页眉与引用等解析结果。渲染核对发现视觉 Transformer 综述部分双栏行仍混排；多级表格有回退正文，独立长表格可能截断。本轮固定相同输入公平比较，不同步调优解析器；错误可能来自解析、分块、相关性标注或模型，不能仅凭排名断言根因。后续应结合 Bad Case 扩大论文与标注规模，再测试混合检索和模型重排。

课程最终要求的 10–20 篇论文、50+ 问答和完整系统评测仍待后续完成；本轮 96 条查询属于 48 个配对意图，不能冒充 96 道独立系统评测题。`reports/评测集.json` 未改动。

历史中文网页实验保留在 [旧结果](../../reports/5_1_3%20向量化与存储/Embedding对比结果.json) 与 [数值复核](../../reports/5_1_3%20向量化与存储/Embedding数值复核.json)：50 题、767 个抽样网页候选，两模型 Hit@5 均为 100%，当时基于速度选择 M3E。其数据、候选难度和用途不同，与本轮数字不可直接相减；当前选择依据为本轮中英文论文实验。

## 6 复现与业务接入

在项目根目录使用项目 `.venv`：

```bash
# 首次准备原始论文，校验每份 PDF 的固定版本和标注位置。
.venv/bin/python "reports/5_1_3 向量化与存储/prepare_paper_benchmark.py" --download

# 首次准备两模型固定权重；已有本地权重时省略 --download。
.venv/bin/python "reports/5_1_3 向量化与存储/compare_embeddings.py" --download --sample data/raw/embedding_papers/sample.json --output /tmp/Embedding论文双语复测.json

# 本地输入准备完毕后，无需联网，三轮复测另存，保留当前记录。
.venv/bin/python "reports/5_1_3 向量化与存储/compare_embeddings.py" --sample data/raw/embedding_papers/sample.json --output /tmp/Embedding论文双语复测.json
```

[准备脚本](../../reports/5_1_3%20向量化与存储/prepare_paper_benchmark.py) 使用已锁定的论文和标注，PDF 或切分变化时停止；[实验脚本](../../reports/5_1_3%20向量化与存储/compare_embeddings.py) 同时保留旧网页基准的复现入口。权重和完整论文正文位于 Git 忽略目录，公开交付只保留来源、标注与真实测量数据。复测应另存结果；计时会随硬件与负载波动。

`config.yaml` 保留唯一选定的 `moka-ai/m3e-base`、固定 revision、本地目录、CPU 和批次 32。`get_embeddings()` 输出 768 维归一化浮点列表；M3E 不加查询前缀。

```python
from src.data_loader import load_document
from src.chunking import split_documents
from src.retrieval.vector_store import get_embeddings

chunks = split_documents(load_document("data/raw/论文.pdf"))  # 替换为实际论文路径。
embeddings = get_embeddings()  # 首次加载本地 M3E，之后在进程内复用。
vectors = embeddings.embed_documents([chunk.page_content for chunk in chunks])
zh_vector = embeddings.embed_query("论文使用了什么优化器？")
en_vector = embeddings.embed_query("Which optimizer does the paper use?")
```

加载使用 `local_files_only=True`、`trust_remote_code=False`，缺少权重明确报错；修改模型配置后重启进程。本阶段提供中英文向量化接口；后续已完成 Chroma 持久化/增量索引与 Top-K 操作封装，见 [向量数据库对比与选择](5.1.3%20向量数据库对比与选择.md)，并接通 [页面批量向量化与增量索引](5.1.3%20批量向量化与增量索引.md)。混合检索仍待实现。

验证：新增语言分组宏平均测试，与现有指标/接口/加载器/分块/页面测试合计 84 个通过；`pip check` 通过。真实两模型测量、结果哈希及从逐题排名重算的总体/分组指标均通过核对。模型质量来自上述真实实验，单元测试 mock 不参与计时或质量评分。
补充验证：选定 M3E 在 `HF_HUB_OFFLINE=1` 下实际编码中英文文档和查询，均为 768 维、有限值、L2 归一化，进程内实例复用正确。
