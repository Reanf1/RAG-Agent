# 5.5.2 系统性能评估

## 1 评测方案与范围

本轮采用5.5.1锁定的60题、12篇论文和1694个原文块，不按系统输出修改问题、参考答案或证据。先完成五组检索，再运行两组Agent，均使用真实本地权重与业务接口；索引、原文复制件及业务日志位于隔离工作目录，原有知识库和会话不受评测数据影响。

固定方案见[评测方案](../../reports/5_5_2%20系统性能评估/评测方案.json)。本轮参数对比为：纯向量、混合、混合＋BGE重排候选20，以及候选10/40；Agent对比默认规则路由与关闭规则路由，其余配置相同，模型请求均设seed=20261003。业务 `config.yaml` 不修改，默认候选20仍保留。

候选数按现有HybridRetriever接口同步控制向量/BM25各路召回量，以及RRF融合后交给重排的块数；因此10/20/40对比是检索候选配置实验，不是固定召回池的单独重排截断实验。五组最终均返回5块。

读取固定上游RAG混合检索、Agent调用流程、指标收集及对应测试，沿用真实接口与隔离数据的分层方式。上游Token估算不用于本次成绩：本地Ollama实际响应提供prompt_eval_count/eval_count，本轮记录真实用量。关闭规则路由是评测进程中的消融，不替换原有ReAct或工具实现。

## 2 指标定义

| 指标 | 本轮口径 |
| --- | --- |
| Hit@5 | 前5块至少匹配一个标注论文物理页 |
| MRR@5 | 前5块首个匹配的原始块排名倒数，未命中为0 |
| Recall@5 | 前5块覆盖的不同标注页数量/该题不同标注页总数 |
| 论文覆盖率@5 | 命中的不同标注论文数量/所需论文数量 |
| 全部论文命中@5 | 所需论文各至少命中一个标注页 |
| 工具选择准确率 | 60题中，实际调用路径属于预先允许的工具路径的比例，不用模型自报正确 |
| 平均推理轮次 | 每题done.iterations的均值，含失败或未完成题；一轮含三个ReAct阶段 |
| 平均端到端延迟 | 用户问题进入run_react到done的实际秒数均值，含工具、检索和日志；不含索引/预热 |
| Token | 汇总各次真实Ollama响应；缺失用量标未知，不按字符推算或重复累加事件快照 |
| 人工质量 | 评阅人逐题填写0～4分的正确性、完整性、引用准确性，记录理由、姓名及日期 |

原文页匹配要同时核对文档指纹与物理页；同页重复块去重，跨页块按真实起止页覆盖。当前标注未穷尽相关块或替代来源，同页匹配不能证明片段语义支持全部陈述。因此本轮是页级检索评测，不与旧开发集的块级Recall直接比较。MRR/Recall均截断至5，没有冒充全库不截断指标。

对于工具指标，全部题允许知识库工具；对比题还允许用真实ID对比所需论文，文献列表可作前置步骤。只列文献、无工具或调用无关工具不算正确。该指标衡量工具选择，参数语义、实际执行成功、回答正确仍须分别核对，不把选择正确等同于答案正确。

每题为独立单轮用户任务，没有继承前题历史、缓存答案或参考答案。Agent结果包含实际工具结果和公开决策轨迹，Token按每次HTTP返回独立记账；并行调用也只记实际模型请求。失败题仍进入平均延迟和决策准确率分母；用量不完整请求单列，不按0 Token处理。

对应300条实际检索记录见[五组结果](../../reports/5_5_2%20系统性能评估/检索五组结果_20261003.json)。默认重排20相对纯向量增加26.67个百分点，但没有达到背景的85%；单独混合检索反而下降3.33个百分点。候选40更慢且成绩未优于20，不因候选更多就宣称效果更好。

默认重排20的全部标注论文命中率仅38.33%，平均论文覆盖率50.33%。对比/归纳题需多篇来源，“至少一页命中”不足以代表完整回答。各类型及中英查询的分组数据已随原始结果保存；所有来源文档英文，不宣称中文原文检索得到验证。

## 4 Agent与答案质量记录

本轮以完整两组60题记录为准，先行验证不计入成绩。模型自报task_complete仅作为终止行为记录，不作为答案正确性。原始答案和工具来源保持原样，不能因为回答失败、缺引用或拒答而删除样本。

| 配置 | 工具选择准确率 | 平均轮次 | 平均完整响应(s) | 平均实际Token | 自报完成数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 默认规则路由 | 81.67% | 1.5833 | 44.264 | 14506.40 | 25/60 |
| 关闭规则路由 | 85.00% | 1.5833 | 44.297 | 14780.98 | 22/60 |

全部120条请求用量完整，626次实际模型调用均保留。默认组输入845721、输出24663，总计870384 Token；关闭规则组输入861474、输出25385，总计886859。默认组Token少约1.86%，延迟少约0.08%，本次没有验证大幅节省或显著提速。默认组结束原因完成/信息不足/重复调用/错误为25/29/5/1，关闭规则组为22/35/2/1。配置保持原样，本轮不依据自报完成率替代人工质量或调优。

已经观测到的例子包括F002：两组选择知识库工具，却将有原文依据的DeiT训练数据问题回答为信息不足；F001最终答案比工具内RAG答案简化了引用标记。是否支持具体陈述及评分高低需按原文人工核验。本轮不做迭代修复，避免一边测试一边改系统或金标准。

S009默认组7轮、152.70秒后触发重复调用终止；S013两组因模型工具列表重复或超过独立调用上限而报错。此类失败均进入60题分母，并将实际错误回答交给评阅人评分。

人工评阅表应使用正确性、完整性、引用准确性三项独立分数，不能用命中率、关键词匹配或助手主观评分替代。0分是实际差评，空白是未评；三项分数、理由、评阅人和日期齐备后才能汇总。评分标准如下：

| 分数 | 正确性 | 完整性 | 引用准确性 |
| --- | --- | --- | --- |
| 0 | 无法回答或核心事实错误 | 未覆盖必要要点 | 无有效引用或来源/位置虚构 |
| 1 | 多数核心事实错误 | 只覆盖少量要点 | 少量有效，多数不支持陈述 |
| 2 | 部分正确但有实质错误 | 约半数要点或遗漏重要项 | 部分支持，存在关键错误或多来源遗漏 |
| 3 | 核心正确，仅轻微错误 | 大部分覆盖，仅轻微遗漏 | 主要陈述可追溯，少量不精确 |
| 4 | 关键事实正确，推断边界明确 | 全部必要要点覆盖 | 必要陈述均有正确论文/物理页，多来源覆盖完整 |

按用户选择，交付[空白人工评分表](../../reports/5_5_2%20系统性能评估/答案质量人工评分表.xlsx)，由用户或评阅人填写后回传。含120条实际答案、参考答案及依据；[回读结果](../../reports/5_5_2%20系统性能评估/人工评分待填核验_20261003.json)为0条已评，均值null。用户填回后可用同目录`summarize_human_scores.mjs`核对0～4整数、理由/评阅人/日期，再汇总；当前没有人工质量分数或质量柱状图。

[性能工作簿](../../reports/5_5_2%20系统性能评估/系统性能评测数据.xlsx)含300条检索和120条Agent公式计算；检索配置、Agent指标、题型/语言三张图见[本节报告](../../reports/5_5_2%20系统性能评估/README.md)。

## 5 验证与首次失败

新增[10项指标边界测试](../../tests/5_5_2%20系统性能评估/test_system_evaluation.py)通过，手算核验第2名倒数0.5、第6名不计分、同页去重、不同论文同页不匹配、跨页块、多来源覆盖、错误工具/论文ID与失败分母。测试没有调用模型，不把这些模拟例子当成真实评测题。

单题先行检索汇总曾错误要求英文组非空，修正为按实际语言分组；首次失败、原始5组排名和修正后的数值复核保留。首次Agent预热因沙箱Metal失败返回HTTP500，获准的本地环境中Metal启用后先行两组验证通过；预热与先行结果不混入正式成绩。

运行环境见[环境记录](../../reports/5_5_2%20系统性能评估/运行环境_20261003.json)，复现命令、参数定义及失败证据入口见[本节README](../../reports/5_5_2%20系统性能评估/README.md)。正式索引约93.829秒，单列索引及模型预热，不计入查询均值。

[数值复核](../../reports/5_5_2%20系统性能评估/评测数值复核_20261003.json)通过300条排名、120条实际轨迹、626次HTTP Token及固定输入/源码哈希。两本工作簿分别1671/120个公式，无错误单元格；6个工作表和3张图已检查排版。首次图表中文缺字的图片保留，使用本机Arial Unicode字体重新生成，修正日志无缺字警告。评测后关闭本次自行启动的Ollama，既有业务索引/会话、源码/YAML和历史性能表保持不变。

## 6 局限

ViT来源与开发集重叠，参考答案未经独立人工复核，不是完全独立来源盲测。本轮单遍、一个硬件环境、论文任务范围，不能推断多用户并发、所有八工具或其它模型/硬件的质量。参数差异只报告本集观测，不宣称统计显著性。独立人工评分完成前，答案质量列必须保持待评。
