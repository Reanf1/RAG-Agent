# 5.1.1 文档加载与批量导入

## 加载器选择

仅实现 PyMuPDF，另外两种方案按用户要求比较官方资料，没有三库同机性能实测。

| 方案 | 适用能力 | 本项目取舍 |
| --- | --- | --- |
| PyPDF2 | 基础分页文本和 PDF 操作；项目已合并回 pypdf | 基础正文可用，阅读顺序和表格仍有歧义 |
| pdfplumber | 字符坐标、表格提取、版面调试 | 表格分析有价值，但无需再维护一套加载器 |
| PyMuPDF | 文本与坐标、页面渲染、表格识别 | 接口简单，同一库支持正文入库及原文页查看，采用此方案 |

依据：[PyPDF2 文本提取](https://pypdf2.readthedocs.io/en/3.x/user/extract-text.html)、[pypdf 项目历史](https://pypdf.readthedocs.io/en/stable/meta/history.html)、[pdfplumber 官方说明](https://github.com/jsvine/pdfplumber)、[PyMuPDF 文本指南](https://pymupdf.readthedocs.io/en/latest/recipes-text.html)。PyMuPDF 官方基准中基础提取耗时为 8.01 秒，PyPDF2 为 101.64 秒（8 个 PDF、7031 页，未重排版面）；这是作者特定样本结果，不能当作本项目成绩或 pdfplumber 成绩。[基准方法](https://pymupdf.readthedocs.io/en/latest/app4.html#text-extraction)

PyMuPDF 为 AGPL／商业双许可，交付保留依赖许可说明。[官方许可](https://pymupdf.readthedocs.io/en/latest/about.html#license-and-copyright)

## 接口与来源

`load_pdf()`、`load_docx()`、`load_text()` 均接收文件路径，返回 LangChain `Document` 列表；`load_document()` 按扩展名分发。来源包含绝对路径、文件名、格式及原始字节 SHA-256 文档 ID。

| 格式 | 读取方式 | 位置与边界 |
| --- | --- | --- |
| PDF | 正文按页；识别表格另返回 Document | 物理页从 1 开始，跳过空页不重编号；全篇无文本、加密或损坏明确失败 |
| DOCX | python-docx 顺序读取顶层段落和表格 | 段落／表格／正文块编号从 1 开始；不伪造页码，不支持旧 `.doc` |
| TXT／Markdown | 标准库 `utf-8-sig` 解码 | 保留 BOM 之外的原文、缩进、Markdown 和 CRLF；整篇读取后分块细化行号 |

Word 使用 `iter_inner_content()` 保持段落与表格交错顺序，空块跳过但位置编号保留。[python-docx 接口](https://python-docx.readthedocs.io/en/latest/api/document.html#docx.document.Document.iter_inner_content)

## 批量导入与重试

`create_import_tasks()` 创建普通字典任务，`batch_import()` 负责加载和持久保存，`batch_build_index()` 继续分块、向量化、增量写入。页面点击“开始导入”后显示进度和成功／失败，成功文件从选择区清除；“重试失败项”每次仅尝试失败文件一轮。

先在临时目录解析，成功后保存到 `data/raw/<内容SHA-256>/<文件名>` 并更新来源路径。同名不同内容分开保存，本批相同名称与内容去重。索引失败保留原文及已写入块，重试补缺失块，不重算成功项。默认单文件 20 MB，前端和批量函数均校验。

进度含失败项，100% 表示本轮尝试结束；任务状态只存在当前页面会话，刷新后可能清空，磁盘原文与索引仍保留。损坏文件、非 UTF-8 文本需先修正；不自动无限重试。
