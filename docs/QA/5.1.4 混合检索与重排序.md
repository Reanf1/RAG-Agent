# 5.1.4 混合检索与重排序

> 状态口径（2026-10-09）：当前实现与验收以[技术设计](../%E6%8A%80%E6%9C%AF%E8%AE%BE%E8%AE%A1%E6%96%87%E6%A1%A3.md)为准。带日期的实验数值、截图和“本轮／待完成”描述属于对应历史阶段；自动回归、真实链路、助手初评与用户审核分别记录，局部复测不替代完整题集。Word／PPT保留10月7日快照，按用户安排待结论确定后重建。

## 检索链路

向量和 `rank_bm25.BM25Okapi` 各召回候选 → 手写 RRF → 取融合 Top-20 → 本地 `bge-reranker-base` 精排 → 返回 Top-5。候选不足时使用实际数量，不补造 20 项。

- BM25：英文按词、中文按单字，先 NFKC 归一化；只返回有词项交集的块，保留真实零／负分。空语料不建索引，`rebuild()` 从 Chroma 正文更新语料而不重算向量；增删后长期复用的实例需重建。
- RRF：`score(d)=Σ 1/(60+rank_i(d))`，排名从 1 开始，按稳定块 ID 融合；相同正文不同来源保留。`rrf_fusion()` 手写，未用框架融合替代。
- 重排：本地 Transformers 对问题与候选编码评分，sigmoid 后降序排序；固定 revision `2cfc18c9415c912f9d8155881c133215df768a70`、批次 8、上限 512 Token。失败明确上报，不以关键词重排冒充模型结果。

余弦、BM25、RRF 和 sigmoid 分数含义不同，不可直接横比，均非答案正确概率。接口统一为 `(Document, score)` 并保留文件／页／块来源。

## 三档质量实验

早期开发集（2026-09-29）：6 篇中英论文、821 块、96 条配对查询，按相关块 ID 计算，三轮排名稳定，质量题数仍为 96。

| 方案 | Hit@5 | Recall@5（块） | MRR@5 | 平均检索毫秒 |
| --- | ---: | ---: | ---: | ---: |
| 纯向量 | 34.38% | 33.16% | 0.2188 | 19.35 |
| 混合 | 35.42% | 33.51% | 0.2597 | 69.53 |
| 混合＋重排 | 45.83% | 42.88% | 0.3788 | 1207.54 |

RRF Top-20 有相关候选 49 题，另 47 题未召回；重排新增 13、丢失 3 条命中。后续 12 篇／60 题的页级基准见[系统评测报告](../../reports/系统评测报告.md)，不能直接比较两种 Recall。均未达到课程宣传的总体 85% 目标。

原始排名、各语言组、公式复核、图表及复现见[5.1.4 报告目录](../../reports/5_1_4%20混合检索与重排序/README.md)。[RRF 参考源码](https://github.com/dsy1018/ai-chatbot/blob/6979d7173ed0f92910a8571dd4ca1b4a171a2c49/app/core/rag.py)、[BGE 重排模型卡](https://huggingface.co/BAAI/bge-reranker-base)。测试覆盖词项、负分、过滤、独立融合公式、实际数据库及重排接口，mock 分数不算模型质量。
