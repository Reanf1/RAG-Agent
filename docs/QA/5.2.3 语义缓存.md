## 2 流程、配置及保守边界

根目录 `config.yaml` 已增加：

```yaml
generation:
  # 原有上下文预算保留。
  cache:
    similarity_threshold: 0.97
    max_entries: 100
```

`SemanticCache` 实例放在 `st.session_state.rag_cache`，同一会话的页面重跑不会丢失缓存，不同会话不共享问题或答案。超容量按最早写入顺序淘汰；重复写入相同问题替换旧条目。“清空当前对话”同时清空本会话缓存；重启页面进程后缓存消失，不作持久化。

1. 创建检索器，仅读取当前 Chroma 正文/元数据并计算有效范围；不先执行检索或加载模型。
2. 同范围内优先精确匹配，仅去除首尾空白，命中无需编码问题。
3. 非相同问题先核对数字、全大写字母开头的标识（如 `BERT-base`）、论文/文献字母ID、否定词、中英文字符及明确的回答语言要求。约束相同才编码查询，选择最高余弦相似度且达到0.97的条目。
4. 未命中继续既有完整RAG流式流程；生成正常结束、非空、至少一个有效正文来源且无警告/无效引用时才写入。`length`、断流、失败、无文档依据及漏正文引用的回答不缓存。
5. 生成后再次核对范围，生成期间知识库变化时不存旧答案。缓存写入失败单独提示，已完成的回答仍可展示。

M3E当前权重的 `max_seq_length=512`；为避免超长问题被截断后误判，超过256字符只允许精确匹配，不参与向量近似匹配。该限制不阻止长问题正常生成，是保守的缓存边界，不把字符数等同于Token数。数字/标识/否定/语言规则同样可能造成漏命中，不是完整的语义等价判断或命名实体识别。

缓存命中展示“原问题”和匹配方式/相似度，来源原文及位置仍可展开。返回值 `usage` 中本次LLM计数为0，原生成计数单独保存到 `original_usage`；不把原来的Token/生成耗时当成本次调用消耗。语义命中仍有一次本地问题编码及范围哈希成本。

## 3 变更失效与来源保留

`cache_scope(store)` 将以下内容稳定排序/序列化后计算SHA-256：

- 当前全部文档块正文与元数据，包含已有稳定ID、文件名及位置。
- 实际Prompt消息模板与版本。
- LLM、Embedding、检索/重排、生成预算与缓存配置，以及索引路径。

每次查询核对范围，范围变化后清空旧条目。新增、删除、同块数替换、正文或页码变化均能失效；仅数据库返回顺序变化不会失效。每次读取小型语料的成本适合本课程规模，不引入索引版本服务或缓存数据库。旧引用只在知识库及配置相同的条件下复用，答案/证据均独立深拷贝，不受调用方修改影响。

界面自动按新缓存配置创建实例。更换实际模型权重后应重启进程，清除已有模型实例及会话缓存；不宣称能检测相同路径/名称下人工替换的权重文件。当前流水线不发送历史，缓存用于独立问题，不能代替后续Agent记忆。

## 6 调用与复测

页面按原手册启动本地模型和Streamlit；缓存自动启用，修改阈值/容量后页面读取新配置。Python入口使用同一有效范围：

```python
from src.generation.cache import SemanticCache, cache_scope
from src.retrieval.vector_store import VectorStore
from src.retrieval.hybrid_retriever import HybridRetriever
from src.generation.rag_pipeline import build_context, generate_answer

cache = SemanticCache()  # 保留此实例供同一会话后续问题使用。
question = "BERT-base有几层？请在事实后标注[参考文档1]。"  # 先完成真实论文导入。
store = VectorStore()
scope = cache_scope(store)
hit = cache.lookup(question, scope)
if hit is None:
    results = HybridRetriever(store).search(question, rerank=True)
    context = build_context(question, results)
    result = {"type": "done", **generate_answer(question, context)}
    if cache_scope(store) == scope:
        cache.put(question, result, scope)
    print(result["answer"])
else:
    print(hit["answer"], hit["cache"], hit["usage"])
```
