## 面板字段与状态依据

左侧“知识库文档”增加已向量化/未向量化提示和“刷新知识库状态”。主区运行指标下方的“知识库管理面板”可展开，包含三项汇总和逐文档表格：

| 字段 | 依据 |
| --- | --- |
| 知识库文档数 | 本地原文和当前索引文档ID的并集，按内容指纹去重；回收目录排除 |
| 已向量化文档数 | 当前Chroma中至少有一个块的文档数 |
| 知识库索引块数 | 当前实际块数之和 |
| 文件名、文档ID | 已保存原文名及块来源，同内容不同名称合并显示 |
| 原文状态 | 真实原文文件存在为“已保存”，仅剩索引为“缺失” |
| 向量化状态、索引块数 | 有块为“已向量化”，无块为“未向量化”，展示实际数量 |
| 导入结果/预期块数/错误（本页） | 当前批次的实际任务状态、分块数量和异常；未知显示“—” |

“已向量化”只表示有索引块，不保证全量完成。部分写入失败时，面板可同时显示已有500块、失败及本次预期501块。当前页旧批次成功也不能覆盖外部删除块后的真实未向量化状态。同内容多个别名的批次结果合并，保留“成功 / 失败”及错误，不用最后一个别名掩盖失败。

刷新重新读取磁盘和Chroma，不重新解析、编码、生成、切换会话或清空问答。读取索引异常明确报错，汇总保持未知，不冒充正常零文档/零块。没有索引时不会为了展示自动创建Chroma，也不会加载Embedding权重。

导入批次状态沿用现有页面存储，不新增持久任务表；浏览器刷新后文件和索引仍可核查，但本页批次结果不补造。未通过解析/未成功保存的上传文件仅显示在本批失败表中，不混入已保存文档列表。表格可横向滚动、搜索及导出，完整文档ID可用于已有限定文档检索。
