# 5.4.4 Windows部署浏览器验收

2026年10月4日，按用户授权访问Windows部署地址`http://192.168.1.12:8501/`进行真实页面验收。用户提供AMD7940HS、32GB、RTX4060 8GB，以及Qwen2.5:7b在Ollama中100% GPU、8192上下文的输出。Mac模型与部署实验继续停止。

已核验健康检查，PDF/Word/TXT/Markdown批量导入、增量索引和失败项重试，向量/BM25/RRF/BGE检索，直接RAG、缓存、低相关暂停与取消、原文物理页查看，计算/追问记忆，以及文档和会话的回收恢复。全库5份184块，输入为公开论文及明确标记的人工样例。

Windows八个本地工具都有实际调用，但整体Agent验收未通过：

1. 含历史的文件名知识库问答，Action传入未确认doc_id被拒绝；真实ID重测成功只是绕过。
2. DETR第一页有摘要，双论文元信息最终回答却称摘要缺失；本地标题解析不兼容`Abstract.`，并出现重复提取。
3. 摘要工具已生成完整四栏带引用答案，Observation继续后第二轮Action调用数量错误，任务失败。
4. 论文对比工具成功，最终回答却漏维度、数据集和节选缺失数字说明。

双论文元信息记录有真实parallel执行，可确认机制运行；时间+关键词则为两轮串行。工具成功率和模型complete均不能代替答案质量。没有Windows终端访问，本轮不是Windows全量回归、60题正式基准或容器验收；长对话、故障恢复、超大文件及正文逐包流式仍待专项重测，人工评分待回传。

本轮仅保存测试资料、报告并更新状态，未修改业务代码或远端部署。原有Mac报告及暂停交接说明保留；本轮Windows秒数是页面单次观察，不与Mac耗时混算。
