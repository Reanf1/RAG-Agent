**测试入口更新（2026-10-03）**：测试已按课程小节拆分，当前入口见[测试目录说明](../../tests/README.md)。本页历史测试数量、耗时及结论保留；复测命令使用当前路径。

实现与验证日期：2026年10月2日。范围为模块四的RAG工具接入及“何时走RAG、何时走联网搜索”；前端Agent面板、监控和健康检查按后续任务完成。

## 1. 参考与复用

修改前读取固定上游版本`6979d7173ed0f92910a8571dd4ca1b4a171a2c49`的`app/core/agent.py`、`app/tools/search.py`、`tests/test_tools.py`及`tests/test_integration.py`。参考其简单工具注册、Function Calling、关联ToolMessage与网页摘要搜索；本项目继续使用已有手写多步ReAct和本机Ollama，不新增Agent框架或服务。

模块三已完成`knowledge_base_search`封装，本次复用该核心工具，不建立第二条RAG流水线：

```text
问题 → Agent规则/模型规划 → Action选择工具及参数
     → knowledge_base_search
     → 向量 + BM25 + 手写RRF + BGE模型重排
     → 模块二上下文预算、Prompt、生成、引用及降级
     → 带来源的ToolMessage/Context → Observation → 回答或继续
```

工具接收`question`和可选上传`doc_id`，返回答案、真实文档/位置引用、分数、状态、耗时和模型用量，并保存既有RAG日志。实际链路只调用一次检索，不先在Agent外预检索后再调用工具。低相关性继续返回`needs_confirmation`；空库保留“当前知识库中未找到相关文档”的纯模型降级提示，不能作为论文证据。

真实联调发现有候选但生成答案没有有效引用。补充最小保护：这种grounded结果返回`insufficient_evidence`，RAG日志标记`incomplete`；Observation采样Schema与原有Python校验均禁止将待确认/资料不足标为完成。该保护检查引用存在及既有映射，不保证引用的语义正确性。

## 2. 来源选择规则

| 用户问题 | 选择与理由 |
| --- | --- |
| 这篇论文用了什么数据集？ | RAG或相应本地论文工具，依据上传原文 |
| 知识库中最新论文的实验结果是什么？ | 本地工具；“最新”限定在本地文献范围 |
| 最新Transformer论文有哪些？ | 启用搜索时选择web_search，查询外部新信息 |
| 上网查找/联网检索论文、search online | 搜索可用时走web_search |
| 什么是Transformer？ | 一般概念直接回答，不强制检索 |
| 查询本地结果，同时查最新外部进展 | 回退模型规划，区分两种来源及任务依赖 |
| 最近的实验代号是什么？ | 有历史时由模型理解会话，不误当作外部资讯 |

规则优先遵守已注册的显式工具选择；本地范围通过知识库/已上传/本文/指定ID等标记识别，英文支持this paper、uploaded paper及latest/recent等常见表达。已有上下文、否定或依赖任务通常保留模型规划，不引入通用意图分类器。

明确的外部请求而web_search不在实际工具列表时，返回`route=unavailable`，`tool_name=null`，附所需工具说明。ReAct输出Thought、action_skipped、Observation和`done.stop_reason=incomplete`，不调用模型、RAG或外网。明确的单一外部任务已路由web_search后，只在本次执行中保留该来源，搜索失败不能以本地旧论文冒充恢复。复合任务仍由已有多步规划完成，不把这条限制用于全部Agent任务。

三个阶段共用“资料来源决策”提示：知识库无结果/低相关性/本地工具失败时不自动联网；网页摘要按标题与URL引用，不编造本地页码；不把完整上传原文、会话或doc_id塞进搜索参数。这些语义与参数边界主要由Prompt约束，不能当作通用隐私过滤器或任意问题的正确路由保证。

## 3. 联网开关与错误边界

`config.yaml`继续保留默认设置：

```yaml
agent:
  online_search_enabled: false
```

如需查询外部公开信息，用户可将该项设为布尔`true`。`get_available_tools()`据此注册额外搜索工具，工具执行时再次检查开关。联网开关控制搜索网站请求；模型始终使用本机Ollama，不静默转云端。显式传入的工具列表仍限定可用工具。

搜索返回最多五条标题、摘要与URL，不抓取链接全文。站点验证页、不可识别响应及网络错误保留为工具失败，不能当作查询成功或无结果。

## 5. 真实模型联调

项目内Ollama + Qwen2.5:7b、本地M3E-base/BGE模型、完整`attention.pdf`及临时Chroma实际入库94块；只隔离配置路径并临时切换已有联网开关，不修改用户文献、索引或默认配置。

首次六项检查中三项通过：本地范围模型规划、外部近期信息模型规划、空库不自动联网。三项失败为：RAG缺有效引用仍标完成；联网关闭却走本地RAG；搜索遇验证页后改用本地旧文献并宣称完成。此记录保留，不能改写为全通过。相应修正后的六项功能检查通过：

| 检查 | 实际结果 |
| --- | --- |
| 本地RAG完整调用 | 回答28.4 BLEU，保留attention.pdf第1页引用及实际doc_id |
| 联网关闭的最新论文请求 | 零模型/工具调用，明确说明不可核验，incomplete |
