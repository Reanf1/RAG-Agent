# 用户使用手册

当前版本提供项目初始化说明页，用于确认基础开发环境和目录。论文管理、智能问答、引用与会话功能尚未接入，完成后将在本手册补充实际操作与截图。

## 1 本地启动

从项目根目录执行：

```bash
# 创建隔离环境，避免修改系统 Python 依赖。
python3 -m venv .venv
source .venv/bin/activate

# 安装基础运行依赖，并启动说明页。
python -m pip install -r requirements.txt
python -m streamlit run src/frontend/app.py
```

Windows PowerShell 的激活命令为 `.venv\Scripts\Activate.ps1`，其余 Python 命令相同。

浏览器打开 http://localhost:8501。可查看五个课程模块的开发状态。当前页面无需 Ollama、模型权重或向量数据库。

Python 支持范围与安装方法见 [Streamlit 官方安装文档](https://docs.streamlit.io/get-started/installation)。当前直接依赖版本固定在 `requirements.txt`；完整业务实现时还需补齐模型库及完整环境记录。

## 2 Docker 启动

已安装并启动 Docker 的环境中，从项目根目录执行：

```bash
# 构建并启动初始化页面。
docker compose -f docker/docker-compose.yml up --build

# 停止并清理本项目容器。
docker compose -f docker/docker-compose.yml down
```

页面仅监听本机 8501 端口。本部署文件当前不启动 Ollama 或数据库，完整系统部署将在业务接入后验证。容器首次构建需要联网下载基础镜像和 Python 依赖。

本次初始化所在机器缺少 Docker Compose 子命令，因此未实测容器构建与启动。执行前可用 `docker compose version` 确认 Compose 已可用。

## 3 文件与配置

- `config.yaml` 的 `app` 字段控制页面名称与描述；其余组是未启用的后续参数样例。
- `data/raw/` 预留给原始论文，`data/index/` 预留给向量索引。
- `logs/` 预留给运行日志。
- 原始课程资料保留在 `docs/`，不会自动导入论文知识库。

## 4 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 提示缺少 streamlit 或 yaml | 在激活环境内重新执行 `python -m pip install -r requirements.txt` |
| 8501 端口已占用 | 追加 `--server.port=8502`，然后访问对应地址；Docker 需调整宿主机端口映射 |
| 配置文件找不到 | 确认 `config.yaml` 位于项目根目录，入口仍在 `src/frontend/app.py` |
| 页面不能上传论文或提问 | 当前为初始化页，对应功能尚未实现 |
| 是否需要下载大模型 | 当前页面无需下载；业务实现后再按经过验证的模型部署步骤准备 |
