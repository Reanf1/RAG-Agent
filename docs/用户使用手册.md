# 用户使用手册

## 1 安装与启动

使用Python 3.10.10。先取得完整项目，在项目根目录创建环境；已有环境直接启动。Windows和macOS/Linux分别安装依赖，不能复制另一系统的`.venv`。

```powershell
# Windows PowerShell
py -3.10 -c "import sys; assert sys.version_info[:3] == (3, 10, 10), sys.version"
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install tzdata
```

```bash
# macOS / Linux
python3.10 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

安装本机Ollama。执行`ollama list`；没有`qwen2.5:7b`时，首次联网执行`ollama pull qwen2.5:7b`。已有服务不重复启动；无服务时在另一个终端执行`ollama serve`并保持运行。默认连接localhost:11434，失败不转云端。

### 首次准备本地权重

需要`data/models/m3e-base`、`data/models/bge-reranker-base`和`data/models/qwen2.5-tokenizer/tokenizer.json`。可复制完整且匹配固定版本的目录，或首次联网下载。Ollama pull不包含这些资源。

将以下Python代码保存在项目根目录，例如`prepare_models_tmp.py`，使用项目虚拟环境执行，下载后删除该临时脚本。Windows命令为`.\.venv\Scripts\python.exe prepare_models_tmp.py`，macOS/Linux为`.venv/bin/python prepare_models_tmp.py`。名称、版本和目录读取[config.yaml](../config.yaml)，Qwen只下载计数词表。

```python
from pathlib import Path
import hashlib
from huggingface_hub import snapshot_download, hf_hub_download
from src.utils.config import load_config

config = load_config()
embedding = config['embedding']
retrieval = config['retrieval']
# 配套JSON包含分词、池化等配置，必须随权重一起准备。
snapshot_download(repo_id=embedding['model'], revision=embedding['revision'],
    local_dir=embedding['local_path'], max_workers=2,
    allow_patterns=['*.json', 'vocab.txt', 'model.safetensors'])
snapshot_download(repo_id=retrieval['reranker_model'], revision=retrieval['reranker_revision'],
    local_dir=retrieval['reranker_local_path'], max_workers=2,
    allow_patterns=['*.json', 'model.safetensors', 'sentencepiece.bpe.model'])
tokenizer = hf_hub_download(repo_id='Qwen/Qwen2.5-7B-Instruct', filename='tokenizer.json',
    revision='a09a35458c702b33eeacc393d103063234e8bc28',
    local_dir=str(Path(config['memory']['tokenizer_path']).parent))
assert hashlib.sha256(Path(tokenizer).read_bytes()).hexdigest() == 'c0382117ea329cdf097041132f6d735924b697924d6f6fc3945713e96ce87539'
print('本地权重与词表准备完成')
```

```powershell
# Windows：启动并允许局域网访问；只需本机访问时地址改为127.0.0.1。
.\.venv\Scripts\python.exe -m streamlit run src/frontend/app.py --server.address 0.0.0.0 --server.port 8501
```

```bash
# macOS / Linux
.venv/bin/python -m streamlit run src/frontend/app.py
```

打开[本机页面](http://localhost:8501)；局域网用部署电脑当前IP与8501端口。保持启动终端运行，Ctrl+C停止。当前Windows部署目录为`E:\工作\RAG-Agent`。

## 2 上传、提问与来源

1. 左侧选择PDF、DOCX、UTF-8 TXT/Markdown，单份默认最多20MiB；点击“开始导入”。进度100%包含失败项，失败原因可展开；修正后“重试失败项”只补失败/缺失块。
2. “科研对话”输入问题并发送，回答流式显示；查看本轮Token、耗时与下方工具/参数/结果执行表，可继续追问。
3. 点击来源核对原文。PDF位置为从1开始的物理页，DOCX为段落/表格，文本为行号；编号合法不表示陈述正确。
4. 低相关结果先查看证据，再确认/取消。确认复用本轮快照生成；取消不做工具内部生成。新问题、会话或知识库变化后需重新确认。

重复上传相同内容跳过旧向量，同名不同内容分别保存；部分入库失败保留已写块供补齐。扫描件无OCR，复杂表格/图片公式需核对原PDF；旧`.doc`应先转换DOCX。

Agent可使用检索、元信息、摘要、对比、关键词、计算、时间和文献列表工具。先“列出已上传论文”核对名称/ID，再提出单篇或多篇任务；对比请说明方法、数据集和结果。联网搜索默认关闭，本地失败不自动联网。

例如“提取澄禾实验.txt的关键词”会读取该文档并返回最多5个有原文依据的词，来源位置可在工具结果中查看。论文对比展示方法、数据集和结果三行，附双方引用；“资料不足”表示本次返回的证据不足，应查看原文，不代表整篇论文没有相关内容。

空库回复明确无文献依据；断流保留部分答案并提示重试；数量/单位或引用核对警告应回到原文检查。警告结果不缓存，但自动检查不能识别所有错答。模型决策阶段仍可能耗Token，缓存命中不保证整个请求零用量。

## 3 检索、知识库与会话

| 页面/操作 | 使用说明 |
| --- | --- |
| 文档检索 | 选择向量、BM25、RRF或模型重排，设置Top-K及可选文档ID，输入问题后检索；只展示原文，不生成答案 |
| 检索分数 | 各方式不可横比，也不是命中概率；Top-1分布用于日志诊断，不是答案正确率 |
| 知识库 | 选文件查看解析正文、原文状态和实际块数；“已向量化”不保证整篇完整入库 |
| 删除知识 | 确认后移除检索块并删除原文；知识库共享，现有对话保留 |
| 新建/切换会话 | 左侧操作，问答/引用/执行表/统计随会话恢复，不再次调用模型 |
| 删除会话 | 删除需确认，删除后不可恢复；保留完整访客URL找回演示历史，该标识不是登录认证 |

### 侧栏状态

“可连接、模型已安装”和“索引可读取”仅检查服务/文件。“最近实际推理成功”和“最近实际向量检索成功”是本页实际业务时间，两项独立更新。

新页面尚无业务记录属正常显示；发送问题、执行向量查询后分别更新。刷新连接保留时间，浏览器重载后重新记录，历史答案/Token仍恢复；切换会话本身不清空时间。缓存/历史/失败/BM25查询不冒充新推理或向量检索，其他Agent阶段真实推理成功仍会更新。业务成功不表示质量审核通过。

## 4 离线与Docker

先联网准备依赖、镜像和完整权重，再离线启动。原生运行可在启动终端设置`HF_HUB_OFFLINE=1`、`TRANSFORMERS_OFFLINE=1`、`OLLAMA_NO_CLOUD=1`；缺资源会报错，不在离线启动时下载。

默认Docker为linux/amd64、CPU推理，Apple Silicon需AMD64仿真。Windows桌面Ollama通常使用`%USERPROFILE%\.ollama\models`；Compose使用项目`data/models/ollama/models`，须复制完整blobs/manifests，保留原运行服务的权重。

```bash
# 首次联网构建；模型须提前准备。
docker compose -f docker/docker-compose.yml up -d --build
docker compose -f docker/docker-compose.yml ps
docker compose -f docker/docker-compose.yml logs --tail=80
docker compose -f docker/docker-compose.yml down
```

访问localhost:8501；data/logs挂载持久保存。app与Ollama运行在internal网络，TCP入口转发页面；容器模型地址覆盖为http://ollama:11434。预备权重后的网络隔离、真实业务及重启持久化已验证，宿主物理断网尚未测试。证据见[课程实验记录](../reports/%E8%AF%BE%E7%A8%8B%E5%AE%9E%E9%AA%8C%E8%AE%B0%E5%BD%95.md)。

## 5 常见问题与维护

| 现象 | 处理 |
| --- | --- |
| 无法访问页面 | 确认启动终端、当前IP/端口；局域网访问需0.0.0.0监听与系统防火墙放行 |
| LLM不可连接/模型未安装 | 检查Ollama服务、11434和`ollama list`，确认YAML目标模型 |
| 本地模型/时区缺失 | 准备完整权重与词表；Windows环境安装tzdata后重启 |
| 检索缺资料/答非所问 | 查看真实原文和过滤ID；核对论文、条件和引用，换明确提问；中文查询英文排名暂缓优化 |
| 文本乱码/导入失败 | 使用UTF-8、转换旧DOC、修复损坏文件；查看失败原因并补缺项 |
| 索引读取失败 | 停止Streamlit，删除 `data/index` 后从原文重新导入 |
| 改分块/解析/Embedding | 从原文在新索引目录重建，验证后切换；旧索引不能修正旧解析正文 |
| 响应慢/中断 | 当前16K/1024在32GB内存、8GB显存Windows可运行；检查任务长度与服务日志，必要时降低预算，勿由此推断最低硬件 |

备份原文、索引、会话SQLite及日志；复制活动数据库前先停应用。实验使用新目录，不覆盖用户库。当前科学答案仍有未完成项，详见[技术设计](%E6%8A%80%E6%9C%AF%E8%AE%BE%E8%AE%A1%E6%96%87%E6%A1%A3.md)和[系统评测](../reports/%E7%B3%BB%E7%BB%9F%E8%AF%84%E6%B5%8B%E6%8A%A5%E5%91%8A.md)。
